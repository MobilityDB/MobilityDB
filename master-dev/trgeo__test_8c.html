Detailed Description

A simple program that tests trgeometry_in(), the public MEOS entry point for reading a temporal rigid geometry from its text representation.

A trgeometry value carries a leading reference geometry ahead of its temporal (pose) part. This test exercises trgeometry_in() directly on a well-formed value and checks that the result round-trips through trgeometry_out().

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o trgeo_test trgeo_test.c -L/usr/local/lib -lmeos
