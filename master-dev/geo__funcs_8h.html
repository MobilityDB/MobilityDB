Detailed Description

The geometry a native implementation works on, decomposed into its edges.

An implementation that answers a question about a geometry without calling GEOS works on the edges of that geometry: the segments and the circular arcs its boundary is made of. The decomposition that produces them lived inside the clipping engine, reachable only from there, so anything else needing it had to build its own. It lives here instead, where every implementation reaches it.
