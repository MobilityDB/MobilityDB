Detailed Description

Test of the canonical outline of an H3 cell of meos/src/h3/h3_geo.c.

For every cell of the resolutions 0 to a maximum, the argument of the program (2 by default), h3_cell_outline must answer, and every vertex a cell shares with a neighbour, a vertex of the neighbour's outline within SHARED degrees, must be that vertex with the same doubles, the extra vertices of the edges crossing a face of the icosahedron included; the cell across each edge must be a neighbour whose outline has an edge across to the cell. The extra vertices appear at the odd resolutions only, and the test fails if none is met there, so that the case they are read for is exercised.
