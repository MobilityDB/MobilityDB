Detailed Description

Test the bin and the tile that contain a value.

A program that tests the functions answering the SQL functions getBin, getValueTile, getTBoxTimeTile and getValueTimeTile, under the noexit error handler.

The bin of a value is the half-open span of the size of the bins starting at the initial value of the bin, which the <type>_get_bin functions return. The tile of a value and a timestamp is the box whose value span and period are the bins of the value and of the timestamp.

The program verifies the answers that the SQL functions give for the same arguments, that each bin starts at the initial value of the bin and has the size of the bins, that each tile is made of the bins of its value and its timestamp, and that a size that is not positive, a missing duration and a bin outside the range of the type are reported by setting meos_errno.

The program also verifies that tbox_time_tiles, which answers the SQL function timeTiles(tbox, ...), gives for a box of any number type the time tiles of the function of its value type.

The functions tiling and boxing by value and time together take both sizes, so a value size of 0 and a missing duration are refused by them, as tbox_get_value_time_tile refuses them.

The program also tests the functions answering the SQL function bins. The bins of a span are the bins that intersect the span, and the bins of a span set are those bins restricted to the span set. A size that is not positive and a span of another type are refused by these functions.

The program also splits a temporal integer, big integer and float into value bins, over a sequence of several bins and a sequence set, and releases what the splits return, so that a leak in a split shows under valgrind.

The program can be build as follows
