Detailed Description

A program that tests the reachability filter as a stream drives it.

The program walks thirteen reports one at a time: the first is 5 km off the track, the twelfth is a teleport after the head of eleven reports. After each report it takes the reports decided since the report before with reachabilitystate_instants and checks how many there are, it checks the counts of the state, and it checks that a state written by reachabilitystate_serialize and read back by reachabilitystate_deserialize walks on as the one written. It closes a session of five reports, more than half of them unreachable, with reachabilitystate_close, which hands back the kept reports of its head, while the final function drops them. It walks each report twice, a report at the time of the report before being walked once, and the walk answers as without the repeats. It then checks the errors of the transition function, of the close and of the reading of the bytes under the noexit error handler.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o reachability_filter_test reachability_filter_test.c -L/usr/local/lib -lmeos
