static void raquet_gdal_release ( GDALDatasetH  ds,
const char *  vpath,
uint8_t *  buf 
)
static

Release the resources a raquet ingest holds.

Every error path calls this before meos_error, because the error handler a host installs need not return to the caller: the PostgreSQL handler leaves through ereport(ERROR) and the standalone one exits, so a release written after the report never runs and the dataset leaks. Reporting last is the idiom the rest of MEOS follows.

Parameters
[in]dsOpen GDAL dataset, or NULL
[in]vpath/vsimem/ path backing ds, or NULL for a real file
[in]bufBand buffer, or NULL
