void sptree_insert_temporal_split ( SPTree *  sptree,
const Temporal *  temp,
int64  id,
int  maxboxes 
)

Insert a temporal value into an in-memory space-partitioning index as several tight per-segment bounding boxes sharing the same id (multi-entry)

The temporal value is decomposed into at most maxboxes tight per-segment bounding boxes, all inserted under id. This yields a more selective index than sptree_insert_temporal for wiggly or high-extent temporal values. When maxboxes <= 1 or the temporal value is an instant, the behaviour is identical to sptree_insert_temporal. Search results may contain the same id several times; use sptree_search_temporal_dedup to collapse them.

Parameters
[in]sptreeThe SPTree previously initialized
[in]tempThe temporal value to be inserted
[in]idThe id shared by every box produced for temp
[in]maxboxesMaximum number of bounding boxes produced for temp
