Detailed Description

Cache of the PROJ transformations and the names of the coordinate reference systems of the SRIDs, in both builds.

PostGIS manages a cache of information obtained from PROJ to speed up transformations (see file libpgcommon/lwgeom_transform.c). The functions of this file are derived from those PostGIS functions; the cache is kept and the systems are read by tspatial_transform_meos.c in MEOS and by tspatial_transform.c in the PostgreSQL extension, as ways_meos.c and ways.c keep the cache of ways_cache.c
