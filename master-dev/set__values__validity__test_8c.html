Detailed Description

A program that tests how the functions answering the values of a set of the MEOS API report a null count under the noexit error handler.

A public MEOS function tests the conditions its internal form asserts, so a binding calling it with a null pointer receives an error it can raise in its host language. The count a function answers through its last argument is such a pointer: it is written once the values are copied.

The program verifies that each of intset_values, bigintset_values, floatset_values, textset_values, dateset_values, tstzset_values, h3indexset_values, npointset_values, poseset_values, posechainset_values, quadbinset_values and s2cellset_values reports a null count by answering NULL and setting meos_errno, and that a valid call answers the values of the set with no error left behind.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o set_values_validity_test set_values_validity_test.c -L/usr/local/lib -lmeos
