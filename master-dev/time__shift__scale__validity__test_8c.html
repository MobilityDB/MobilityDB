Detailed Description

A program that tests how the time shifts and scales of the MEOS API report a null interval under the noexit error handler.

A public MEOS function tests the conditions its internal form asserts, so a binding calling it with a null pointer receives an error it can raise in its host language. An assertion cannot carry that contract: it is compiled out under NDEBUG, which leaves the release build a binding links against with no check at all.

The program verifies that tstzset_shift, tstzset_scale and tstzset_shift_scale, tstzspan_shift, tstzspan_scale and tstzspan_shift_scale, and tstzspanset_shift, tstzspanset_scale and tstzspanset_shift_scale, report each null interval they take by returning NULL and setting meos_errno, and that each answers the shifted and scaled value with no error left behind.

The program can be build as follows
