Detailed Description

A simple program that tests the generic temporal functions on a temporal rigid geometry.

A temporal rigid geometry is a temporal pose carrying a reference geometry, and every generic temporal function of an accessor, a restriction to time or a deletion answers it as the poses the function answers for its temporal pose, carrying the same reference geometry. For each function and each value, the program checks both: the temporal pose of the answer is the answer of the function on the temporal pose of the value, and the reference geometry of the answer is the one of the value. The values are a linear sequence, a step sequence, a sequence set, whose sequences carry no reference geometry of their own, and a sequence of one instant, which a discrete interpolation rebuilds from its instant. Where the function refuses the temporal pose it refuses the rigid geometry too, so the error handler returns rather than exits, and both answers are NULL. The generic writers, temporal_out, tspatial_as_text and tspatial_as_ewkt, write a rigid geometry as its own writers do, its reference geometry before its poses, and the output reads back as the value.
