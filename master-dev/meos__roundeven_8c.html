Detailed Description

The C23 roundeven for a C library that lacks it.

The vendored sin and cos of core-math/ round with __builtin_roundeven, which GCC lowers to a call to roundeven where the target has no rounding instruction for it. The Windows C runtime has no roundeven, and the build compiles this file into the vendored objects only where a call to it does not link. In the default rounding mode, round to nearest with ties to even, nearbyint returns the same double.
