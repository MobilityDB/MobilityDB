Detailed Description

A program that tests that the hexadecimal Well-Known Binary (HexWKB) input of every value refuses a string that encodes no bytes.

A HexWKB string encodes a byte by two hexadecimal digits, so a string of an odd length, or one carrying a character that is not a hexadecimal digit, encodes nothing, and the empty string encodes no byte. The decoder raises an error and returns no bytes for the first two, and the reader of the third finds no endian flag, so the reader must then return no value instead of parsing the bytes it was not given.

For each reader, the program writes a well-formed value as HexWKB, reads it back, and reads it with its last digit removed, with its last character a letter that is no hexadecimal digit, and as the empty string: each of the three must be refused with meos_errno set. meos_typeof_hexwkb, which never raises an error, must answer T_UNKNOWN for the first two.

The program can be build as follows
