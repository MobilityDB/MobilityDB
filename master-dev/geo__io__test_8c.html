Detailed Description

A program that tests the readers and the writers of a geometry and a geography over every representation.

Each reader is given the same point in every representation and reads the representations its SQL names state, and only those: the text and EWKT readers the WKT representation optionally prefixed with an SRID, the binary readers the WKB and EWKB representations, the hexadecimal readers their hex-encoded forms, the GeoJSON readers GeoJSON. A geography reader refuses an SRID that is not a longitude and latitude system and reads WGS84 where the value states none. Each writer writes the bytes of the representation it names. The program prints a row per reader and representation, and a row per writer, and exits with the number of rows that differ from what they state. The program can be build as follows

gcc -Wall -g -I/usr/local/include -o geo_io_test geo_io_test.c -L/usr/local/lib -lmeos
