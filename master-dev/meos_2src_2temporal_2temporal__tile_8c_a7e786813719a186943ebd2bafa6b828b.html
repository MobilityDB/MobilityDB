Set the state with a temporal number and a value and possibly time grid for splitting it.

A split states the value bin of each fragment, so it lays a value grid, which the state of tnumber_value_time_tile_init lays for a positive vsize, as tgeo_space_time_split_init requires its spatial grid

Parameters
[in]tempTemporal number
[in]vsizeSize of the value dimension, which must be positive
[in]durationSize of the time dimension as an interval (accepts NULL)
[in]voriginOrigin for the value dimension
[in]toriginOrigin for the time dimension
[in]border_incTrue when the grid contains the upper border of the extent
[out]ntilesNumber of tiles
