A program that checks that the restrictions of a temporal point cloud point and patch to a point cloud box refuse a box of another schema, as the overlaps of their boxes refuses it, and answer a box of their own schema.

The schema gives the dimensions of a point their meaning, so a value and a box of two schemas have no common extent: the restriction reports the error rather than answering that the value lies outside the box. A minus whose value lies in the box answers NULL too, so the error number tells the two answers apart.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o tpcbox_restrict_validity_test tpcbox_restrict_validity_test.c -L/usr/local/lib -lmeos
