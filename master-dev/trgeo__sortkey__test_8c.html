Detailed Description

A program that tests that a temporal rigid geometry is compared, equated and ordered by its value, its reference geometry and its poses, and that its sort key orders it as its comparison does.

A temporal rigid geometry is a reference geometry moved by a temporal pose, so two values are equal exactly when their reference geometries are equal by value (geo_eq) and their poses are equal, and the comparison reads the reference geometry (geo_cmp) right after the bounding box, before the instants. The program therefore checks, over the values of three reference geometries moved by five spellings of poses, three of them one value spelled as an instant, a sequence of one instant and a sequence set of one sequence:

  • over pairs stated beside each rule, that the equality and the comparison answer as the rule states;
  • over every pair, that the comparison answers 0 exactly when the equality holds and that swapping the operands swaps the sign, and over every triple, that the comparison is transitive;
  • over every pair, that the byte order of the keys is the order of temporal_cmp.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o trgeo_sortkey_test trgeo_sortkey_test.c -L/usr/local/lib -lmeos -lm
