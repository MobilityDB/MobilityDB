Detailed Description

Test that a thread naming no time zone reads and writes timestamps in the zone the program names last.

The main thread names Asia/Kathmandu (+05:45), a zone no test machine keeps, so that an answer in the zone of the machine shows. A worker thread, which names no zone and calls no initialization, as a goroutine or a thread of a pool runs, writes the input with the offset +05:45. The main thread then names America/New_York while the worker waits, and the worker writes it with -05, the last naming winning, as every thread reads the ways file meos_set_ways_csv names last (ways_thread_test.c). The worker then names Europe/Moscow and writes +03; the main thread, which names its own zone, still writes -05, and a second worker naming none writes +03, the zone named last. Each step of a thread waits for the step of the other before it.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -pthread -o zone_thread_test zone_thread_test.c -L/usr/local/lib -lmeos
