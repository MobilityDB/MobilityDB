uint8_t * rasterunionstate_serialize ( const RasterUnionState *  state,
size_t *  size_out 
)

Return the bytes of the state of the aggregate uniting rasters, read back by rasterunionstate_deserialize.

The bytes are the band, the pixel operation, whether it is named and the number of bands, followed for each part of each band by its size and the Well-Known Binary of its raster, a size of 0 for a part not built, as rasteralignstate_serialize writes the Well-Known Binary of its grid
