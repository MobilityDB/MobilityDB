const char * srid_srs ( int32_t  srid,
bool  short_crs 
)

Return the name of the coordinate reference system of an SRID, as the GeoJSON and MF-JSON representations state it.

The short name is the authority and its code, as in EPSG:3857, and the long one is the OGC URN, as in urn:ogc:def:crs:EPSG::3857, the two names the PostgreSQL extension reads from the table spatial_ref_sys. Both are read from spatial_ref_sys.csv together with the projection of the SRID onto itself and kept with it in the PROJ cache, so the file is read once per SRID

Parameters
[in]sridSRID
[in]short_crsTrue for the short name, false for the long one
Returns
The name, owned by the PROJ cache and valid until the cache stores another projection, or NULL with an error where the SRID has no authority in spatial_ref_sys.csv
