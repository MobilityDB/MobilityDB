Detailed Description

Temporal distance for temporal pose chains.

A pose chain reads as the pose its composition gives, so each function answers what its temporal pose sibling answers for the composed value tposechain_to_tpose gives. A chain of more than one link composes to a step function, its value between two instants composing rotations rather than interpolating them, so for such a chain the distance is the one the composed pose holds over each step.
