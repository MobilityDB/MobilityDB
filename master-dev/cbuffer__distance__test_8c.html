Detailed Description

The distance between two circular buffers, judged by the closed form.

The distance between two discs is max(0, D - r1 - r2), D the distance between their centres, and the answer is the double nearest it. The sum of the radii is no double in general, so each case below takes the centres 5 apart, where D is a whole number, and radii whose exact sum lies a few units in the last place below 5: the expected value is then (5 - r2) - r1, each subtraction exact by Sterbenz's lemma since its operands lie within a factor of two of each other, which the program checks before it reads the answer. Subtracting the radii one at a time from 5 rounds the first difference, so the answer is off by units in its last place, and in the first case it is 0 for two discs that do not meet.
