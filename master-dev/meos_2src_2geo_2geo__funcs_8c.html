Detailed Description

Decompose a geometry into the edges a native implementation works on.

An implementation that answers a question about a geometry without calling GEOS works on the edges of that geometry: the segments and the circular arcs its boundary is made of. The decomposition that produces them lived inside the clipping engine, reachable only from there, so anything else needing it had to build its own.
