Detailed Description

A program that tests that the sort key of a set, of a span and of a span set orders them as set_cmp, span_cmp and spanset_cmp do.

Over every pair of a corpus of sets of each set type with a sort key (one, two and three values: negative values, zero of both signs, extremes, infinities, NaN, and texts that are empty, prefixes of one another, hold bytes above 0x7F or a zero byte), of spans of each span type (negative values, zero of both signs, large magnitudes, infinities and every bound flag) and of span sets built from them (one, two and three spans, so that a set whose spans prefix another's is compared with it), the sign of a byte comparison of the two keys must be the sign of the comparison of the two values, and two values the comparison holds equal must have identical keys. The program also verifies that set_sortkey, span_sortkey and spanset_sortkey report a null value and a null size, and that set_sortkey reports a set type without a sort key.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o sortkey_test sortkey_test.c -L/usr/local/lib -lmeos -lm
