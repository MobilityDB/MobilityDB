Detailed Description

A program that tests that a span, a set and a temporal value hold finite timestamps and dates only.

infinity and -infinity have no position on the time line a span, a set or a temporal value bounds and interpolates over, so MEOS refuses them where a timestamp or a date enters such a value (ensure_finite_timestamptz, ensure_finite_date), as it refuses a non-finite number (nan_refusal_test.c). The program reads infinity and -infinity through each kind of entry point and verifies that each case ends in an error: never a value, never NULL without an error, never a crash. The cases are

  • the text readers of the time spans, sets and span sets, of the temporal values and of the boxes;
  • their binary readers, a value holding a sentinel instant being written as hex WKB and the bytes of that instant overwritten with an infinite timestamp or date;
  • the MF-JSON reader of a temporal float, its sentinel instant overwritten with an infinite one;
  • the constructors, conversions and set operations taking a timestamp or a date.

Its controls verify that a finite input is still answered, that a malformed timestamp reports its own error only, and that a predicate over an infinite timestamp answers without an error. Each case runs in a child process, so a case that crashes is reported as such and the others still run.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o infinite_time_refusal_test infinite_time_refusal_test.c -L/usr/local/lib -lmeos -lm
