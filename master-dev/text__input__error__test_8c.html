Detailed Description

A program that tests that the text input of circular buffers, poses and span sets refuses a malformed value and keeps nothing it allocated.

A text parser that reads a part of a value into an allocation, such as the centre of a circular buffer or of a pose, and then finds the rest malformed returns an error, and must free what it read before. Under the noexit error handler a binding keeps running after such an error, so a part left behind is memory lost for each malformed value it reads.

The program reads one malformed value for each error return that follows an allocation in cbuffer_in, pose_in and intspanset_in, verifies that each is refused with meos_errno set, and reads well-formed values that must be accepted. Run under valgrind with --leak-check=full, it reports no block definitely lost.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o text_input_error_test text_input_error_test.c -L/usr/local/lib -lmeos
