int cbuffer_contains_geo ( const Cbuffer *  cb,
const GSERIALIZED *  gs 
)

Return 1 if a circular buffer contains a geometry, 0 if not, and -1 when the relationship cannot be read from the distances.

Containment asks that the geometry be covered and that the two interiors meet. A covered geometry that reaches the interior of the disc at any of its points meets it, since the interior is open, so the containment fails only for a geometry that lies entirely on the boundary circle, which is where its nearest point is at the radius
