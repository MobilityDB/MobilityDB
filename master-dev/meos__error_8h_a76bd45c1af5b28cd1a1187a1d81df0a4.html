enum errorLevel

Levels of the messages an error handler receives, with the values PostgreSQL gives them, so that a handler installed with meos_initialize_error_handler tells an error from a warning without the PostgreSQL headers.

They are named apart from PostgreSQL's ERROR, which the Windows header wingdi.h also defines.

A message of level MEOS_ERROR reports a failure: the function returns its sentinel and the error number records the code. A message of a lower level accompanies an answer and leaves the error number as it is.
