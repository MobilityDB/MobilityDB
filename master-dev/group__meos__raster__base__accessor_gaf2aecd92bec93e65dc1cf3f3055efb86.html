MeosPixType raquet_pixtype_from_string ( const char *  str)

Return the pixel data type corresponding to a name.

Parameters
[in]strPixel type name: UINT8, INT8, UINT16, INT16, UINT32, INT32, UINT64, INT64, FLOAT16, FLOAT32, or FLOAT64
Note
This is the parser counterpart of raquet_pixtype()
The name is read without regard to case, so the lower-case spelling the RaQuet specification gives the type field of a tile carries straight through from a file into the constructors. The name raquet_pixtype() returns keeps the upper case the SQL surface documents
The name PostGIS raster gives a pixel type is accepted for the same type, so the band type an ST_BandPixelType call reports carries into the constructors as it stands. The types PostGIS carries in less than a byte a pixel say that a Raquet band has no representation for them
