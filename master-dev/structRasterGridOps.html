Detailed Description

What a raster engine tells the sampling about its grid: where a position lies in it, the value of a pixel, where a segment reaches one of its lines, and where it lies.

The descriptor plays for a raster grid the part DggsCellOps plays for a DGGS: the sampling names one of these instead of repeating the engine's arguments at every entry point, and an engine fills it in one place. The PostGIS raster, a GDAL file and a Raquet tile answer the same questions and differ only in how.
