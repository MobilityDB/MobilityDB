Detailed Description

What a raster engine tells the sampling about its grid: how to read a value, how far apart two positions of a walk over it are, and where it lies.

The descriptor plays for a raster grid the part DggsCellOps plays for a DGGS: the sampling names one of these instead of repeating the engine's four arguments at every entry point, and an engine fills it in one place. The PostGIS raster, a GDAL file and a Raquet tile answer the same three questions and differ only in how.
