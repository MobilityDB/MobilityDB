Detailed Description

A program that tests the ever/always set-set relationships over arrays of temporal geos, i.e., the *_tgeoarr_tgeoarr functions, against the scalar relationship applied to every pair.

The oracle is the scalar relationship of the same name, so the array function is checked against the per-pair answer it is meant to reproduce, including the cases its bounding box prefilter decides without an exact test. A pair with no common time is excluded, matching the drivers.

The array sizes straddle the number of pairs above which the drivers index both sides and join the trees rather than comparing every pair, so both paths are exercised and asserted to give the same answer.

The program can be built as follows
