Datum Raster_set_values ( PG_FUNCTION_ARGS  )

Return a raster whose band takes the values of an array over a block of pixels.

The arrays are read as Raster_clip_bands reads its arrays, with the shape of the block

Parameters
[in]rastRaster
[in]nbandNumber of the band, starting at 1
[in]xColumn of the upper left pixel of the block, starting at 1
[in]yRow of the upper left pixel of the block, starting at 1
[in]newvaluesetValues of the block, a NULL one setting the pixel to nodata
[in]nosetTrue for a value not to set, absent where every value is set; a block of its own, read over the block of the values
[in]keepnodataTrue to leave the pixels holding the nodata value
Note
Not STRICT: the flags left out set every value, and a NULL keepnodata takes its default @sqlfn setValues()
