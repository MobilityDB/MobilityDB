Detailed Description

A single entry of the kNN cursor's priority queue.

An entry is either a tree node still to be expanded (is_leaf_entry false, node set) or a leaf id ready to be emitted (is_leaf_entry true, id set), keyed by dist, the distance from the query box to the entry's bounding box.
