Detailed Description

Check a native spatial operation against the assertions of the GEOS test suite.

The corpus is produced by geos_harvest.py and holds one wkt|arg|expected record per line, where expected is the result the GEOS project asserts for the operation. The comparison criterion is the one the reference project applies to that operation:

  • a convex hull is an exact answer, so the result must equal the assertion;
  • the GEOS suite asserts no oriented envelope, so that operation is checked against the answer of GEOS itself, exactly, both being rectangles that no approximation stands between;
  • a buffer is an approximation, and this implementation answers it with exact circular arcs where GEOS polygonizes them, so the two results necessarily differ vertex by vertex. The criterion is therefore the one BufferResultMatcher of the GEOS test runner applies: the symmetric difference covers less than MAX_RELATIVE_AREA_DIFFERENCE of the expected area, and the oriented discrete Hausdorff distance between the two boundaries stays under a hundredth of the buffer distance. The arcs of the native answer are stroked before the comparison, since an area and a Hausdorff distance are defined on the polygonal representation.

Usage:

geo_op_diff convexhull < convexhull_corpus_geos.txt
geo_op_diff buffer < buffer_corpus_geos.txt
geo_op_diff orientedenvelope < any corpus, whose first field is read
geo_op_diff issimple < issimple_corpus_geos.txt

The program compares two engines, so unlike its siblings it does not build against the installed MEOS alone: it reads the geometry through liblwgeom and answers the reference through GEOS, and neither header nor symbol is part of the MEOS library surface. It builds against the source and build trees, where $SRC is a MobilityDB checkout and $BLD its build directory

gcc -Wall -g -DMEOS=1 -I$SRC/meos/include -isystem $SRC/pgtypes \
-isystem $BLD/pgtypes -isystem $SRC/postgis -isystem $BLD/postgis \
-isystem $SRC/postgis/liblwgeom -isystem $BLD/postgis/liblwgeom \
-o geo_op_diff geo_op_diff.c -lmeos $BLD/postgis/libpostgis.a \
-lgeos_c -lproj -ljson-c -lm
