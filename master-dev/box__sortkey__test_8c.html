Detailed Description

A program that tests the sort keys of temporal, spatiotemporal and point cloud boxes.

The sort key of a temporal box, of a spatiotemporal box and of a point cloud box must order them as tbox_cmp, stbox_cmp and tpcbox_cmp do. Over every pair of a corpus of boxes of each box type, the sign of a byte comparison of the two keys must be the sign of the comparison of the two boxes, and two boxes the comparison holds equal must have identical keys and be equal. The temporal boxes mix integer, big integer (with the 64-bit extremes) and float value spans, with and without a period, and periods alone. The spatiotemporal and point cloud boxes cover three SRIDs, every combination of the space, z, time and geodetic flags, zero of both signs, large magnitudes and infinities, and for point cloud boxes schema ids up to the largest unsigned value. The program also verifies that tbox_sortkey, stbox_sortkey and tpcbox_sortkey report a null box and a null size.

The program can be built as follows
