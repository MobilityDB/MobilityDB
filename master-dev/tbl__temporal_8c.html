Detailed Description

A simple program that reads the CSV file of every temporal type and applies a function to the values it holds.

The corresponding SQL query would be, for each temporal type in turn,

SELECT k, numInstants(tprecision(temp, interval '5 minutes', timestamptz
'2000-01-03'))
FROM tbl_tfloat;

The function is one every temporal type answers, so one run reports every type rather than the one a reader uncomments. To exercise a type-specific function instead, apply it to the value the loop parses.

The fixtures are written by tools/gen_test_csv.py from the archives the PostgreSQL suite loads.
