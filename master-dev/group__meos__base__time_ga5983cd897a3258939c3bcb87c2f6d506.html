bool timetz_to_parts ( const TimeTzADT *  timetz,
int64 *  us,
int32 *  offset 
)

Return in the last two arguments the microseconds from midnight and the offset from UTC of a time with time zone.

A binding converts a time with time zone to the time of its host through this function and back through timetz_from_parts, as timestamptz_to_unix_us converts a timestamptz. The offset is in seconds east of UTC, as ISO 8601 and the hosts state it: a time with time zone holds the seconds west of UTC, so that 12:00:00+01 has the offset 3600.

Parameters
[in]timetzTime with time zone
[out]usMicroseconds from midnight
[out]offsetSeconds east of UTC
Returns
On error return false
