GSERIALIZED * trgeometry_geo_common_dims ( const Temporal *  temp,

Return the copy with no Z of a geometry with Z related to a temporal rigid geometry without Z, and NULL otherwise, as tgeo_geo_common_dims gives it for a temporal geo.

A temporal rigid geometry in two dimensions reads a geometry in three dimensions in two, as its distances do. A NULL argument answers NULL, so the validity function the caller runs next reports it (ensure_valid_trgeometry_geo)
