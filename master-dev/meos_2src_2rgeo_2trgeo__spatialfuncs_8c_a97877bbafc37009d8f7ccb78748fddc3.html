◆ body_on_excluded_border()

static bool body_on_excluded_border ( const GSERIALIZED *  body,
const STBox *  box 
)
static

Return true where a body meets a box only along the borders the box leaves out.

A box of a grid is half-open, [xmin,xmax) x [ymin,ymax), so the tiles either side of a grid line claim a value lying on that line exactly once. The overlap of two geometries is a closed test and answers true for a body that merely touches, so a body every point of which stands at or beyond one of the two upper borders meets the closed box while meeting no point of the half-open one

Parameters
[in]bodyBody, already placed in the world
[in]boxBox whose upper borders are left out
Note
A body reaching past an upper border and back is admitted, so this decides exactly the case where the contact is confined to a border and never withholds a box the body genuinely reaches
