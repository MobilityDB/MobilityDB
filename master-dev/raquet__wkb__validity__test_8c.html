Detailed Description

A program that tests how the reading of a Raquet tile from its Well-Known Binary representation reports dimensions no tile can have.

The WKB of a Raquet tile writes its width and height as 32-bit integers, while a tile holds between 1 and 65535 pixels a side. The program verifies that a WKB stating a width or a height outside that range is refused with MEOS_ERR_WKB_INPUT under the noexit error handler, whatever payload follows, and that the dimensions a tile can have are read back.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o raquet_wkb_validity_test raquet_wkb_validity_test.c -L/usr/local/lib -lmeos
