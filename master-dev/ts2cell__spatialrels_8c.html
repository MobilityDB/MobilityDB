Detailed Description

Ever spatial relationships for temporal S2 cell indices.

These functions convert a temporal cell index into the temporal geography of its cell boundary and answer with the ever spatial relationships of the temporal geography, on the sphere. They are C functions rather than SQL wrappers converting to tgeography, so that the planner support function tspatial_supportfn fires and the spatial index (GiST/SP-GiST) accelerates the predicate. The box of an S2 cell holds its geodesic edges, which is what lets the index filter on it.
