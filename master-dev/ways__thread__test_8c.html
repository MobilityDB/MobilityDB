Detailed Description

Test that every thread reads its routes from the ways CSV file named last.

A program that writes two network files in the current directory and removes them at the end, as ways_index_test.c writes its files: the first holds a route 1 of length 5 and a route 4 of length 10, the second a route 1 of length 2 and a route 10 of length 1. The main thread names the first file; a worker thread, which keeps the routes it reads in a cache of its own, reads route 1 and route 4 of it. The main thread then names the second file while the worker waits, and the worker reads route 1 of the second file, no route 4 and route 10; the main thread reads the same, then names the first file again, and the worker reads route 1 of the first file. Each step of a thread waits for the step of the other before it, so the threads never read and name a file at once.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -pthread -o ways_thread_test ways_thread_test.c -L/usr/local/lib -lmeos -lm
