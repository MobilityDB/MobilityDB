bool ways_cache_lookup ( WaysCache *  cache,
int64  gid,
bool  any_gid,
ways_fetch_fn  fetch,
ways_record *  rec 
)

Return in the last argument the record of a route, read from the ways cache or else from the ways network, and return false when there is no such route.

The geometry of the record belongs to the cache. A route whose geometry the cache released is read again from the network, and only its geometry is kept, since its entry is still there.

Parameters
[in]cacheWays cache
[in]gidRoute identifier
[in]any_gidTrue when the record of any route is asked for
[in]fetchFunction reading a route from the ways network, which allocates the geometry it returns in the context of the cache
[out]recRecord of the route
