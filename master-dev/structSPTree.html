Detailed Description

In-memory space-partitioning index (quad-tree or k-d tree)

Works on Span and TBox. Each node is a data box that partitions the space; the family-specific geometry (quadrant assignment, child region, and consistency tests) is provided through function pointers, reusing the same routines as the SP-GiST operator classes.
