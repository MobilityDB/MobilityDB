Detailed Description

A program that tests that the comparison of point cloud values is a total order consistent with their equality that orders them first by their pcid, and that their sort keys order the sets and the temporal values of these types as their comparison does.

pgPointCloud defines no order on a point or a patch, and the only order it states, along the decoded dimensions, needs the schema of the pcid. A comparison reads no catalog, so it orders two values first by their pcid as a number and then by the stored bytes that follow it, as unsigned bytes, a value prefixing another sorting first, and holds them equal exactly when their meaningful bytes are. A sort key is the string of bytes whose unsigned byte order is the order of the comparison. The program therefore checks, over points and patches of the pcids 1, 2, 256 and 257, whose schemas have three dimensions, and 3, whose schema has two:

  • over every pair, that the comparison answers 0 exactly when the equality holds, that swapping the operands swaps the sign, and that two values of different pcids are ordered as their pcids are;
  • over every triple, that the comparison is transitive;
  • over every pair of sets of one and of two values, and of temporal values of one and of two instants, that the byte order of the keys is the order of set_cmp and temporal_cmp, which refuses two temporal values of mixed 2D and 3D dimensions, those of the pcid 3 and those of the others.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o pointcloud_sortkey_test pointcloud_sortkey_test.c -L/usr/local/lib -lmeos -lm
