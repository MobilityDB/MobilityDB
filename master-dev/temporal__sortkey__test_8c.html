Detailed Description

A program that tests that the sort key of a temporal value orders temporal values as temporal_cmp does.

Over every pair of a corpus of temporal values of each temporal type with a sort key, the sign of a byte comparison of the two keys must be the sign of temporal_cmp, and two values temporal_cmp holds equal must have identical keys and be equal by temporal_eq. The corpus holds, over three values at three times, instants, discrete sequences, step and linear sequences with every bound flag and sequence sets, among them the one-element wrappers of an instant and of a sequence and a discrete sequence beside the set of its one-instant sequences, which temporal_eq holds equal. The program also verifies that temporal_sortkey reports a null value, a null size and a temporal type without a sort key.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o temporal_sortkey_test temporal_sortkey_test.c -L/usr/local/lib -lmeos -lm
