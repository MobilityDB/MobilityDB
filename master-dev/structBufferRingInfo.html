Detailed Description

Topological classification of a closed buffer boundary ring.

  • ring Boundary ring
  • pieces The ordered pieces used to construct the ring. The ring owns the geometric representation, while this array contains copies of the BufferPiece descriptors needed by later topology stages.
  • parent is the index of the immediately containing ring, or -1 when the ring has no containing ring.
  • depth is the number of containing rings between the ring and the exterior. Even depth means shell, odd depth means hole.
  • shell identifies the shell which directly owns the ring when the ring is a hole. It is -1 for shells.
