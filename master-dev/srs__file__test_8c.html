Detailed Description

Test that the MEOS build reads a spatial reference system from the spatial_ref_sys.csv file meos_set_spatial_ref_sys_csv names last.

A program that writes two files byte for byte in the current directory, as ways_index_test.c writes its networks, and removes them at the end. They state SRID 4326 alike, SRID 3857 under the authorities EPSG and MYAUTH, and SRID 990001, under an authority PROJ does not know so that its proj4text defines it, as a Mercator projection and as longitude and latitude. Under each file in turn, the name geo_as_geojson states for SRID 3857, as crs_name_test.c reads it, and the point of SRID 4326 at (10, 10) transformed to SRID 990001 by geo_transform, are the ones of that file, though the systems of the first one were read before the second one is named.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o srs_file_test srs_file_test.c -L/usr/local/lib -lmeos -lm
