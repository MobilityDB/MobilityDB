Return the minimum spatial distance between two arrays of temporal circular buffers.

Time-agnostic, equivalent to the distance between the union of the traversed areas of the first array and that of the second, as mindistance_tgeoarr_tgeoarr answers for temporal geos. The pairs are taken nearest box first (tspatialarr_pairs) and each is measured by mindistance_tcbuffer_tcbuffer capped at the running minimum, so the search stops once no pair left can improve it and no traversed area is built

Parameters
[in]arr1,arr2Arrays of temporal circular buffers
[in]count1,count2Array lengths
Returns
Minimum spatial distance, DBL_MAX for an empty array
