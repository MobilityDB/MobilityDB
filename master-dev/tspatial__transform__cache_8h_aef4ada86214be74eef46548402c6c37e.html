MEOSPROJSRSCache * GetMEOSPROJSRSCache ( void  )

Get the Proj object cache from the global variable.

If it does not exist, a new blank one is made in a child of the CacheMemoryContext, as GetWaysCache makes the ways cache, and returned. Its entries are made in that context by AddToMEOSPROJSRSCache, so the cache serves the backend for its life; the systems are read from the table spatial_ref_sys.

Get the Proj object cache from the global variable.

If it doesn't exist, or holds the systems of a file other than the one meos_set_spatial_ref_sys_csv names last, make a new blank one and return it, as GetWaysCache of ways_meos.c makes its cache anew: the systems of a file answer for that file alone. The path of the file is held per thread with the cache, so each thread's cache follows the file it reads.
