Open a raster file via GDAL and fill its grid descriptor, which every raster_value_gdal wrapper reads.

Parameters
[in]pathPath to a GDAL-readable raster file
[in]band_numBand number (1-based)
[out]ds_outOpen GDAL dataset; the caller closes it with GDALClose
[out]ctxSampling context, valid while ds_out stays open
[out]opsDescriptor of the raster grid
Returns
true on success; on failure sets a MEOS error and returns false
