Pose * pose_make_point3d_ypr ( const GSERIALIZED *  gs,
double  yaw,
double  pitch,
double  roll 
)

Construct a 3D pose value from a 3D point and a yaw / pitch / roll triple.

The angles are in radians and are read in the ZYX intrinsic Tait-Bryan convention the OGC GeoPose Basic-YPR conformance class prescribes, the same convention pose_ypr() decomposes into. This is the inverse of that accessor: a pose built here and decomposed there returns the angles it was given, modulo the wrap the decomposition applies and the gimbal-lock degeneracy at pitch = ±π/2, where yaw and roll are no longer separable.
