Detailed Description

Multi-entry support of the temporal point clouds: the keys of a value are the point cloud boxes MEOS splits it into.

The extraction methods of their multi-entry classes, as trgeo_mest.c holds those of the temporal rigid geometries; each calls the internal twin of a splitter or a merge of the temporal point clouds, whose boxes carry the point cloud schema of the value
