Detailed Description

Test the in-memory indexes over boxes of different structures.

A program that tests that an R-tree, a quad-tree and a k-d tree holding temporal, spatiotemporal and point cloud boxes of every set of axes answer every search operation as the operation applied to every stored box does, as a scan of the boxes would: the set of boxes it holds for, or the error it raises on the boxes of some structure. For each box type and tree, 240 boxes cycling through the sets of axes of the type are inserted, every search operation is asked with four queries of every set of axes, and the cells where the index answers otherwise are counted, which must be none. The test that an operation raises no error, index_op_is_valid, is checked against the operation itself on every ordered pair of boxes of different structures, value span types, SRIDs, geodetic flags and schemas included. The nearest-neighbour cursor of each tree over temporal and spatiotemporal boxes is asked with the same queries and answers the distances of every stored box in increasing order, or the error the distance raises on some stored box, and the test that the distance raises no error, index_distance_is_valid, is checked against the distance itself.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o index_structure_test index_structure_test.c -L/usr/local/lib -lmeos -lm
