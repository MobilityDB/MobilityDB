Detailed Description

A program that tests every function taking the name of a time zone with a zone it knows and with a zone it does not know.

Under an error handler that returns, as the handlers of the bindings do, a function given a time zone it does not know raises one error and returns its error value: an infinite timestamp, NULL for a time with time zone. Given a time zone it knows, it raises no error and returns the value PostgreSQL returns. The known zone is Europe/Zurich in summer, two hours ahead of UTC.
