Return a raster whose band takes the values of an array over a block of pixels, as PostGIS's ST_SetValues

The values are the block row by row, its upper left pixel at (x, y). A value stated as nodata sets the pixel to the nodata value of the band, or to the least value of its type where the band states none; a value stated as not to set leaves the pixel as it is, as does keepnodata for a pixel holding the nodata value of the band. A pixel of the block beyond the raster is left out, and a value beyond the pixel type is read into it as rt_core reads it
