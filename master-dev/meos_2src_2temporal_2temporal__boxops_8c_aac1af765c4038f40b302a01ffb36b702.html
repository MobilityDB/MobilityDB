◆ index_distance_apply()

double index_distance_apply ( MeosType  bboxtype,
const void *  box,
const void *  query 
)

Return the nearest approach distance of a stored box and a query.

Shared by the in-memory RTree and SPTree indexes. Where index_distance_is_valid states that the distance raises an error on the boxes of a tree, a nearest-neighbour search measures a box stored in it, which raises the error the operator |=| raises over the stored boxes: the one of the validators of NAD_tbox_tbox for temporal boxes, of nad_stbox_stbox for spatiotemporal boxes and of nad_tpcbox_tpcbox for point cloud boxes

Parameters
[in]bboxtypeType of the bounding boxes
[in]boxStored bounding box
[in]queryQuery bounding box
Returns
On error return DBL_MAX
