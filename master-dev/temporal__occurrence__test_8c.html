Detailed Description

A program that tests the occurrences of a temporal value at its origins.

A template built from a reference origin occurs at every origin of a set, shifted by the elapsed duration from the reference origin. The program checks one occurrence against the value written by hand, and the origins whose occurrence meets a period in two ways: on cases whose bounds touch, where the inclusion of each bound decides, and against the definition over a grid of periods, every origin's occurrence being built and its period tested for overlap with the period, for templates with each inclusion of their bounds and for an instant.
