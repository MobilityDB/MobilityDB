static

Build the convex-hull STBox pre-filter and the reusable ST_Value FunctionCallInfo shared by every raster sampling/restriction/predicate wrapper.

Arg 2 (the point) of fcinfo_val is left uninitialized: it is set on every call by raster_st_value_sample. The FmgrInfo backing fcinfo_val is palloc'd so that its lifetime matches the calling wrapper's memory context, same as the LOCAL_FCINFO buffer itself.
