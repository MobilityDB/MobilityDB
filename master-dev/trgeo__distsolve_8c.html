Detailed Description

Function family and root isolation for the distance between rigid geometries.

Every equation that the distance algorithm solves has the form

F(t) = SUM_k [ (a1_k*t + a0_k) * cos(w_k*t) + (b1_k*t + b0_k) * sin(w_k*t) ]
+ c2*t^2 + c1*t + c0

This file evaluates such functions, differentiates them, and finds all their roots on an interval.

The file includes no PostgreSQL, PostGIS or MEOS header and does no allocation, so that it builds on its own, without libmeos. This lets meos/test/unit/rgeo/trgeo_distsolve_unit.c test the root isolation against dense sampling on millions of random functions, with the same code that MEOS uses. Do not add palloc, Assert or meos_error: they need MEOS, and Assert and meos_error can jump out of a function, which would also make the control flow differ between the two builds.

See meos/src/rgeo/trgeo_distance.txt for the derivation of the family.
