Detailed Description

A program that tests that an error raised below the first element of a path ends the path modification of a JSONB value.

Under an error handler that returns, jsonb_set, jsonb_insert and jsonb_delete_path answer NULL with the error PostgreSQL 18 raises for the same path: a NULL element, an array index that is not an integer, or an existing key an insertion would replace, reached at any depth.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o jsonb_set_path_error_test jsonb_set_path_error_test.c -L/usr/local/lib -lmeos
