Detailed Description

The values a trajectory reads from a raster series.

A raster that changes in time is a series of rows (validtime, rast), each raster valid over its period, never a temporal raster: a value [r1@t1, ..., rn@tn] would carry a whole raster at every instant, and nothing between two rasters interpolates. A trajectory reads a series as it reads one raster, each raster over the part of the trajectory within its period, in the order of the periods. The functions here read a series of PostGIS rasters and a series of Raquet tiles through the public functions reading one raster, raster_value() and raster_tile_value(), so no code of the vendored raster core is read here.
