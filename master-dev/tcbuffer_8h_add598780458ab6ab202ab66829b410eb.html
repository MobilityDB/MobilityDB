◆ tcbufferseg_clear_of_box_ctx()

bool tcbufferseg_clear_of_box_ctx ( const Cbuffer *  cb1,
const Cbuffer *  cb2,
const void *  ctxv 
)

Return true if a disk moving linearly from cb1 to cb2 stays clear of the box of the geometry of a context.

As in the coarse prune of dist_segm_nad, over the segment the centre lies between its two ends and the radius does not exceed the larger of the two, so the disk keeps inside the box of the two end centres grown by that radius. A disk that keeps beyond the box of the geometry along one axis neither meets the geometry nor lies in it, and the touches, contains and covers relationships are false over the whole segment. The test is exact: a difference of two doubles is rounded to the nearest double, which is monotonic, and the radius is a double, so a difference read above the radius is above it exactly. A stationary disk is the segment whose two ends are equal. The function returns false for a disc context and for a geometry without a box.
