Detailed Description

A simple program that tests the coordinates and timestamps of the instants of a temporal point.

The program reads each instant of a temporal point a second way, through its sequences, the public instants of each sequence, the temporal floats of its coordinates and its start timestamp, dropping an instant that repeats the last one of the previous sequence, and compares what it reads with the arrays tpoint_coords answers. The arrays of a sequence are given back to tpointseq_make_coords, which makes the sequence again. The temporal points are generated, geometric and geodetic, with and without Z, instants, discrete, linear and step sequences and sequence sets, among them sequence sets whose sequences meet at an instant. The errors of the function are read too.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o tpoint_coords_test tpoint_coords_test.c -L/usr/local/lib -lmeos
