Detailed Description

Test of the planar walk of meos/src/h3/h3_geo.c.

A planar segment is straight in longitude and latitude, and so is each edge of the outline of a cell (h3_cell_outline), so the walk h3_segment_cells leaves each cell where the signs of the outline say it crosses an edge or passes a vertex, the crossings ordered by segment_edge_cross_cmp, every sign exact on the input doubles. The rows are trips whose cells, those each segment holds for a positive length, an exact oracle in rational arithmetic sharing no code with MEOS states, each a trip the base walked otherwise: on the curved boundaries of the library it misses the cell a segment cuts across a corner of the outline, passes a vertex into the wrong cell, or holds the cell along whose edge the segment runs where the rule gives the edge to the cell across. A visit at one parameter, a pass through a vertex, holds no length: the walk states the crossing it enters each cell by, and the visit whose crossing and next crossing lie at one parameter is left out.
