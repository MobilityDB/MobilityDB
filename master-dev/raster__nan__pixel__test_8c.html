Detailed Description

A program that tests that a pixel holding NaN reads as no value.

No MEOS value holds a NaN. A raster marks a pixel without data by its nodata value, which GDAL writes as NaN for a float band, so a pixel holding NaN carries no value: a trajectory read over it answers no value there, as it does over a pixel equal to the nodata value, rather than a temporal float holding a NaN, which every MEOS constructor refuses.

The program reads a trajectory over a one-pixel Raquet tile of 64-bit floats, as raster_tile_value reads it in raster_validity_test.c: a pixel of 7.5 answers a value, and a NaN pixel, whether the band declares NaN as its nodata value or declares none, answers no value and raises no error.

The program can be build as follows
