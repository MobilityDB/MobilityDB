Detailed Description

Ever spatial relationships for temporal network points.

These functions dispatch to the temporal geometry point implementation through the conversion of a temporal network point into the temporal geometry point it travels along its route, whose box is the box of the temporal network point. They are defined as C functions (rather than SQL wrappers casting to tgeompoint) so that the planner support function tspatial_supportfn fires and the spatial index (GiST/SP-GiST) accelerates the predicate.
