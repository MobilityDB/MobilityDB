Detailed Description

Ever/always and temporal comparisons for the temporal pgpointcloud types.

Mirrors meos/src/cbuffer/tcbuffer_compops.c and meos/src/quadbin/tquadbin_compops.c: every flavour is a thin typed wrapper over the generic eacomp_* / tcomp_* kernels, so the temporal pgpointcloud types carry the same orthogonal comparison grid as the other spatial families.

Note
Two values with different pgpointcloud schemas (pcid) simply compare unequal here; a mismatch is not an error. That is this family's established convention — its restriction functions return NULL rather than raising on a pcid mismatch — and it keeps the behaviour of the already-deployed eEq / aEq, which bind the generic Ever_eq_temporal_base, unchanged. The pcid is enforced where mixing schemas would build an ill-formed value, namely set construction (ensure_same_pcid_pcpoint in pcset_meos.c).

Ordering comparisons (<, <=, >, >=) are not lifted: only equality and inequality are exposed, as in the other spatial families.
