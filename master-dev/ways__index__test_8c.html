Detailed Description

Test how the MEOS build reads a route of the ways CSV file.

A program that tests which line of the ways CSV file answers a route, on two files it writes in the current directory and removes at the end, as tnpoint_stops_test.c writes its network: the first holds a route of length 5, a route whose only line has an empty geometry, a route whose first line is empty and whose second has length 2, and a route of length 10 on a last line without its newline; the second holds a route of length 1.

The program verifies that route_exists and route_length answer the route of each line, the first line with a geometry that is not empty for a route on two lines, no route for one whose geometry is empty or that the file lacks, the routes of the second file once meos_set_ways_csv names it, and the first file again after meos_finalize_ways.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o ways_index_test ways_index_test.c -L/usr/local/lib -lmeos -lm
