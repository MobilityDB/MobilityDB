Detailed Description

The integer inputs of the points of the outline of an H3 cell.

The two loops below follow _faceIjkToCellBoundary and _faceIjkPentToCellBoundary of the vendored h3lib/lib/faceijk.c, step for step, and record the inputs H3 gives _hex2dToVec3 where those functions compute coordinates (h3_vertex_recipe, h3_edge_extra_recipe), so that gnomonic_face_point_nearest states the point exactly. The loops read the tables of faceijk.c (adjacentFaceDir, faceNeighbors, maxDimByCIIres, unitScaleByCIIres), which are static there, so this file includes it rather than linking it; it includes vertex.c for the same reason, to read vertexRotations and its direction tables (h3_cell_vertexes). It is built with the vendored library in the object library h3core, whose definitions stay out of the dynamic table of MEOS (as the vendored core-math/ in coremath), since MEOS also loads libh3 and its own definitions of those names. Whether an edge crossing a face of the icosahedron bends at an extra vertex is the one decision H3 takes in doubles (_v2dAlmostEquals of _v2dIntersect): the crossing is read here on the integers of the lattice, where it meets an end of the segment exactly or lies a fraction of the segment away from it.
