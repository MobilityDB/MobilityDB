bool * meos_error_save_begin ( bool *  occurred)

Save the errors raised until meos_error_save_end instead of raising them.

The twin of passing an ErrorSaveContext to an input function of PostgreSQL. An error of a value a parser refuses, that is, a text that is no value of the type, a value beyond the range of the type or an argument value it refuses, sets occurred and leaves both the handler and the error number as they are, the parser returning its sentinel. Any other error, such as an internal one or an allocation that fails, is raised as usual, as PostgreSQL raises it whatever the context. The pair nests as meos_errno_reset and meos_errno_restore do: this function returns the state it replaces and meos_error_save_end puts it back.
