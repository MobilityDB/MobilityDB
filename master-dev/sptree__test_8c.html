Detailed Description

Test the in-memory space-partitioning index.

A program that tests the in-memory space-partitioning index (quad-tree and k-d tree), i.e., sptree_create_*, sptree_insert and sptree_search, against an exact brute-force oracle.

For the five span types, the temporal box, the spatiotemporal box with and without Z and the point cloud box, and for both the quad-tree and the k-d tree kinds, a set of boxes is inserted and every search operation the box type answers is compared with the exact set of boxes satisfying the operator. Two properties are asserted per configuration and operator: (i) no false negatives: every box satisfying the operator is a candidate; (ii) no false positives: every candidate satisfies the operator. Instants sharing a bound the query excludes, the multi-entry indexes and the nearest-neighbour cursor are asserted in both kinds of tree, and what the cursor refuses to open on and the kinds of tree the constructors refuse separately.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o sptree_test sptree_test.c -L/usr/local/lib -lmeos -lm
