Detailed Description

A program that tests that every MEOS value is a finite number.

NaN and the infinities have no position among the finite numbers, so MEOS refuses them where a number enters it (ensure_finite, ensure_finite_geo), and an operation of finite operands whose result leaves the doubles raises an error (ensure_finite_result). The program reads NaN, +Infinity and -Infinity through each kind of entry point, and calls operations over finite operands near the largest double, and verifies that each case ends in an error: never a value holding a non-finite number, never a non-finite result, never a crash, nor a value returned together with an error. A result lying between finite values is answered: a case expecting one checks its value. Each case runs in a child process, so a case that crashes is reported as such and the others still run. The cases are drawn from the census of doc/contributing/exactness/NAN-POLICY.md:

  • the text readers of the pose and circular buffer families, of boxes, spans, sets, temporal floats and geometries;
  • their binary readers, and those of float boxes and span sets, a value holding the sentinel 1234.5 being written as hex WKB and its eight bytes overwritten with a non-finite double;
  • their MF-JSON readers, the sentinel overwritten with a bare non-finite token;
  • public functions taking a non-finite double;
  • operations over finite operands whose result leaves the doubles, and operations whose intermediate leaves them while the result does not.
