Detailed Description

A program that tests that no MEOS value holds a NaN.

A NaN has no position among the numbers, so MEOS refuses it where a number enters it (ensure_not_nan, ensure_not_nan_geo), and an operation whose result would be NaN raises an error. The program reads a NaN through each kind of entry point and calls the operations that make one from infinite values, the inputs a float accepts, and verifies that each case ends in an error: never a value holding a NaN, never a NaN result, never a crash, nor a value returned together with an error. Each case runs in a child process, so a case that crashes is reported as such and the others still run. The cases are drawn from the census of doc/contributing/open_questions/NAN-POLICY.md:

  • the text readers of the pose and circular buffer families, of box3d and of geometries;
  • their binary readers, and those of float boxes and span sets, a value holding the sentinel 1234.5 being written as hex WKB and its eight bytes overwritten with a NaN;
  • their MF-JSON readers, the sentinel overwritten with the bare token NaN;
  • public functions taking a NaN double;
  • operations over infinite floats whose result would be NaN.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o nan_refusal_test nan_refusal_test.c -L/usr/local/lib -lmeos -lm
