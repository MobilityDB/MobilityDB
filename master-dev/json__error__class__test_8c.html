Detailed Description

A program that tests that an SQL/JSON error reports the error code of the class PostgreSQL gives it.

The JSON twin of pgtypes_error_class_test.c. Each jsonpath is applied once to a value on which PostgreSQL raises an error, which must report through meos_errno the MEOS code named after the errcode PostgreSQL raises with the same message, and once to a value it answers, which must report none: a method on a value of the wrong type MEOS_ERR_NON_NUMERIC_SQL_JSON_ITEM, .datetime() of a number MEOS_ERR_INVALID_ARGUMENT_FOR_SQL_JSON_DATETIME_FUNCTION, an operator on several items MEOS_ERR_SINGLETON_SQL_JSON_ITEM_REQUIRED, the accessors of an array, of an object and of a member on a value that is none MEOS_ERR_SQL_JSON_ARRAY_NOT_FOUND, MEOS_ERR_SQL_JSON_OBJECT_NOT_FOUND and MEOS_ERR_SQL_JSON_MEMBER_NOT_FOUND, a subscript out of bounds MEOS_ERR_INVALID_SQL_JSON_SUBSCRIPT, the minus of a string MEOS_ERR_SQL_JSON_NUMBER_NOT_FOUND, a variable the variables do not hold MEOS_ERR_UNDEFINED_OBJECT, and a key repeated in a JSON object read with unique keys MEOS_ERR_DUPLICATE_JSON_OBJECT_KEY_VALUE.
