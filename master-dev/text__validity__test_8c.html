Detailed Description

A program that tests how the text functions of the MEOS API report a null text under the noexit error handler.

A public MEOS function tests the conditions its internal form asserts, so a binding calling it with a null pointer receives an error it can raise in its host language. An assertion cannot carry that contract: it is compiled out under NDEBUG, which leaves the release build a binding links against with no check at all.

The program verifies that text_lower, text_upper, text_initcap and textcat_text_text report a null text by returning NULL and setting meos_errno, as meos_array_get reports a null array, that a valid call still answers with no error left behind, and that the temporal forms ttext_lower, ttext_upper, ttext_initcap and textcat_ttext_ttext, which read the internal forms at each instant, answer the base answers at each instant.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o text_validity_test text_validity_test.c -L/usr/local/lib -lmeos
