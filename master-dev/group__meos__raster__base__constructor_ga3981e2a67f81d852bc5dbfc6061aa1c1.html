Return the tile of one band of a row of a Raquet file.

A Raquet file is a Parquet table whose rows are the tiles of a raster, keyed by their QUADBIN cell in the column block, the row of block 0 holding the metadata of the file as JSON. An engine that reads Parquet scans the rows itself and hands each to this function with the metadata, which states the size of a tile (tiling.block_width, tiling.block_height), the type and nodata value of each band (bands), the layout of the bands (band_layout: sequential, one column per band, or interleaved, the bands of a pixel side by side in one column) and their compression (compression: none, gzip, which the zlib form also reads as, or jpeg or webp, an image of every band). The pixels are little-endian, row by row from the top, as the specification states. A band stating a scale or an offset is refused, the tile holding the stored numbers alone
