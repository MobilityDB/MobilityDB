Detailed Description

Randomized test of the closest-feature walk of meos/src/rgeo/trgeo_distwalk.c.

The test runs the walk on random segments and compares the events with the true distance, see tu_check(). Body A is a random convex polygon that moves and rotates. Body B is, in turn:

  • a static point;
  • a moving point;
  • a static segment;
  • a moving and rotating segment;
  • a static convex polygon;
  • a moving and rotating convex polygon, which rotates at the same rate as A in half of the cases. Then pairs of edges keep their relative direction, and some can stay parallel for the whole segment.

Half of the segments keep B away from the path of A, so that both the disjoint and the overlapping cases are frequent. Half of the segments also give a random distance level, whose crossings must be events, as for tDwithin.

The argument is the number of segments. ctest uses a small number; run the program with 20000 for a deeper check.
