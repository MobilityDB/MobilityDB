Detailed Description

A program that tests that every text output of MEOS states the size of the string it returns.

A function returning a string the caller frees writes its size, the terminating null character included, through its size_out argument, so that a binding copies the string without scanning it for the terminator. For one value of each kind the program checks that the size written is the length of the string plus one: the temporal values of each subtype, the sets, spans and span sets, the boxes, the geometries in each of their formats, the spatial temporal values and sets with and without their SRID, MF-JSON compact and pretty, the circular buffers, the network points, the poses and pose chains with their GeoPose documents, the rigid geometries, the cells, the JSON values, the base values written by the PostgreSQL output functions, and the version and style strings. It also checks that a null size_out is refused with meos_errno set, as the hex WKB writers refuse it.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o text_size_test text_size_test.c -L/usr/local/lib -lmeos
