bool sptree_insert ( SPTree *  sptree,
void *  box,
int64  id 
)

Insert a bounding box into an in-memory space-partitioning index.

The box is stored at the first empty child slot reached while descending from the root by quadrant. Equal boxes chain through the first child, so the search still finds every id.

The depth a box reaches depends on the order the boxes arrive in, so a tree grown from an ordered set is deep and prunes little. sptree_load builds the same index from a whole entry set at once and chooses the depth itself.

Parameters
[in]sptreeThe SPTree previously initialized
[in]boxThe bounding box to insert
[in]idThe id associated with the box
