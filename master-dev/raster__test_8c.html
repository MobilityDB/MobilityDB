Detailed Description

A program that tests the input and output functions of the PostGIS raster type, and the band count read through them.

A Raster is the serialized form of the PostGIS raster type. A PostgreSQL session reaches it by detoasting its own column, but every other binding holds the interchange representation instead, so raster_num_bands() is reachable outside PostgreSQL only through raster_from_wkb() / raster_from_hexwkb(). This program exercises that path with no PostgreSQL involved, which is what makes the band count inheritable by the language bindings rather than a PostgreSQL-only operator.

The two rasters below are the ASCII hex-encoded WKB of the two rasters the numBands case of mobilitydb/test/raster/queries/500_raster.test.sql builds with ‘ST_AddBand(ST_MakeEmptyRaster(3, 3, 0.0, 3.0, 1.0, -1.0, 0.0, 0.0, 4326), '32BF’, 0.0, NULL)`, so that the two suites read the same values.

The program can be build as follows
