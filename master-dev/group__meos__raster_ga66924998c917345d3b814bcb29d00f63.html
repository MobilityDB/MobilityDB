Return a trajectory restricted to the instants where the sampled raster pixel value falls outside a float span.

Equivalent to, with v = #raster_value(traj, box, sample, ctx):

atTime(traj, getTime(minusSpan(v, vspan)))
Parameters
[in]trajTrajectory (temporal geometry point)
[in]boxBounding box of the raster used as a pre-filter, may be NULL
[in]sampleCallback returning the pixel value at a point
[in]ctxOpaque context passed through to the callback
[in]vspanFloat value range to exclude
Returns
