◆ eaoverlaps_tnpoint_stbox()

static int eaoverlaps_tnpoint_stbox ( const Temporal *  temp,
const STBox *  box,
bool  ever 
)
static

Return 1 if a temporal network point ever (or always) lies in a spatiotemporal box, 0 if not, and -1 on error, as eaoverlaps_tgeo_stbox answers it for a temporal geo.

The value ever lies in the box when its restriction to the box by tnpoint_restrict_stbox is not empty, and always lies in it when its restriction to the complement of the box is empty; a box with only the T dimension restricts the value to its period

Parameters
[in]tempTemporal network point
[in]boxSpatiotemporal box
[in]everTrue for the ever semantics, false for the always semantics
