Detailed Description

Test the key-value mode of the skiplist.

A program that tests the skiplist in its key-value mode, in which a MEOS program accumulates one value per key, as the AIS example ais_expand_skiplist.c does per vessel. The list is filled in the three ways the mode allows: (i) one value at a time, searching for its key and inserting the value only when the key is absent, then updating the stored value in place; (ii) sorted batches of values whose key is a field of the value; (iii) sorted batches of keys given apart from their values.

Every batch after the first holds keys that are already in the list, so its values are merged with the stored ones by the merge function of the list, which is tried in its two forms: one that updates the stored value in place and returns it, and one that returns a new value.

After every step the list must hold each key once, in increasing order, with the sum of the counts given for it, and its length must be the number of keys.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o keyval_skiplist_test keyval_skiplist_test.c -L/usr/local/lib -lmeos
