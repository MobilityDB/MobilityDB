Detailed Description

A program that tests that the equality of spans and span sets agrees with their comparison and their hash on the zeros of both signs, as the equality of sets does.

The doubles -0.0 and 0.0 are equal, so [-0, 1] and [0, 1] are the same float span, both written [0, 1]: span_cmp answers 0 and span_hash gives them one hash, and span_eq, spanset_eq and set_eq must answer true.

The program can be built as follows

gcc -Wall -g -I/usr/local/include -o span_zero_sign_test span_zero_sign_test.c -L/usr/local/lib -lmeos -lm
