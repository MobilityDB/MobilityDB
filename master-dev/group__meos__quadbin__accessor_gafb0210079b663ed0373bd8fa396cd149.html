Set * quadbinset_compact_cells ( const Set *  cells)

Return the compacted set of a QUADBIN cell set.

Return the compacted set of cells, and the set of cells at resolution resolution covering cells.

A cell covered by a coarser cell of the set is dropped, and every four children of one parent merge into that parent, from the finest resolution up, so the result covers the region of the set with the fewest cells
