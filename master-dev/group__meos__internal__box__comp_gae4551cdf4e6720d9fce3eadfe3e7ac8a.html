uint8_t * tbox_sortkey_intl ( const TBox *  box,
size_t *  size 
)

Return the sort key of a temporal box.

The key is the flags, written as an integer, the span type of the value dimension, then the bounds of the period when the box has a time dimension and the bounds of the value span when it has a value dimension, as span_sortkey_intl writes them, so that comparing two keys byte by byte as unsigned values orders the boxes as tbox_cmp does and two boxes have the same key when tbox_eq holds. The span type orders the boxes of integer, big integer and float values, which are one type, before their value spans.

[in]boxTemporal box
[out]sizeNumber of bytes of the key
