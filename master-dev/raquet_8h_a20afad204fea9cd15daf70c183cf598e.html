uint8_t * raquet_sortkey_intl ( const Raquet *  rq,
size_t *  size 
)

Return the sort key of a Raquet tile.

The key holds the fields in the order raquet_cmp compares them, as npoint_sortkey_put writes those of a network point: the quadbin cell as an unsigned 8-byte integer, the pixel type as one byte, the width and the height as unsigned 2-byte integers, each most significant byte first, then the pixels as they are stored. Two tiles whose fields before the pixels are equal have pixels of one size, so comparing the keys byte by byte orders them as raquet_cmp does, and the keys are identical exactly when raquet_eq holds. The nodata value, which raquet_cmp does not read, is not part of the key
