4/* The following functions have the same name as the C symbols of the h3-pg
5 * PostgreSQL extension. The MEOS library defines them (they are the public
6 * binding surface); the MobilityDB PostgreSQL extension does not, so that
7 * both the h3 and mobilitydb extensions can be loaded in the same server.
8 * Input reads, and output prints, the canonical hexadecimal cell literal
9 * with an optional "0x" prefix and at most 16 significant digits. Input
10 * additionally requires the value to denote a cell, a directed edge or a
11 * vertex, the zero sentinel aside, so that no value without a location
12 * enters the type. Comparison / ordering / hashing operate on the uint64
13 * cell identifier; they carry no geographic meaning but are required for
14 * ordering, grouping, and hashing, and so apply to any of the modes. */
