Detailed Description

A raster band whose pixels cannot be read raises an error rather than reading as a band without values.

Two rasters are read along a trip over them. Each opens, and each fails at the first pixel it is asked for:

  • a PostGIS raster whose band is stored outside the database in a file that does not exist, read through the vendored raster core;
  • a GDAL virtual raster whose band takes its pixels from a file that does not exist, read through GDAL.

The values read along the trip, the restrictions and the ever and always predicates must each raise an error: no value, never and always would each state something about a band nobody read. The SQL suite pins the raster core cases; the GDAL readers are reached from C, so this program holds them.
