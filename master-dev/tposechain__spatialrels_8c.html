Detailed Description

Ever spatial relationships for temporal pose chains.

These functions dispatch to the temporal geometry point implementation through the temporal pose a temporal pose chain composes to (tposechain_to_tpose) and the temporal geometry point of its position (tpose_to_tpoint), the conversion the casts tposechain::tpose and tpose::tgeompoint perform. The box of a temporal pose chain bounds every joint, the composed pose among them, so it bounds the temporal geometry point. They are defined as C functions (rather than SQL wrappers casting to tgeompoint) so that the planner support function tspatial_supportfn fires and the spatial index (GiST/SP-GiST) accelerates the predicate.
