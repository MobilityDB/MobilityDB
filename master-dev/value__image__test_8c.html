Detailed Description

Test the size and the copy of the flat memory image of every value type.

A binding can carry a MEOS value as its flat memory image: it writes the number of bytes the value states with its _mem_size function and reads them back into a value with its _copy function. A value of a fixed-size type has the size of its structure.

The program verifies, for a value of each type, that the image of the size the value states is the whole value: the bytes copied out of it answer equal to the value, the copy of those bytes holds the same bytes and states the same size, and a null argument is reported by answering the error value each function documents and setting meos_errno.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o value_image_test value_image_test.c -L/usr/local/lib -lmeos
