Detailed Description

Test of the functions of the walk of meos/src/rgeo/trgeo_distwalk.c.

Each function of the walk gives a DistFun that must be equal to an expression of the placed geometry. The test compares the two for random bodies and segments, with a moving and a static second body.

CMake builds the test in a MEOS build with rigid geometries, see CMakeLists.txt in this directory:

cmake -S . -B build -DMEOS=ON -DPOSE=ON -DRGEO=ON
make -C build && (cd build && ctest -R trgeo_dist)
