Detailed Description

Test that the like_regex predicate of a JSON path answers and leaves no memory behind.

A like_regex predicate builds the text of its pattern on the first string it tests, and the cache of compiled regular expressions keeps a copy of that text of its own. The program evaluates paths holding a like_regex on strings the pattern matches, on strings it does not match, and on a value that is not a string, which the predicate answers as unknown without building the text, and checks each answer. Run under valgrind with –errors-for-leak-kinds=definite, as the MEOS smoke workflow runs every load test, a pattern text left behind by an evaluation fails the run.

The patterns number fewer than the 32 entries of the cache, so no compiled expression is dropped from it.
