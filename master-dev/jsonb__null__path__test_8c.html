Detailed Description

A program that tests how the JSONB functions of the MEOS API taking an array of keys or path elements read a NULL element.

A NULL element of the array is a NULL of the SQL array the function is derived from, and each function answers what PostgreSQL 18 answers for it: jsonb_extract_path and jsonb_extract_path_text answer NULL for a path holding a NULL element, jsonb_exists_array and jsonb_delete_array skip a NULL key, and jsonb_delete_path, jsonb_set and jsonb_insert report "path element at position N is null" when the path reaches the element and answer their argument unchanged when it does not. The extractions of a JSON text, json_extract_path and json_extract_path_text, and those of a temporal JSONB, a temporal JSON and a JSONB set answer NULL for such a path as well, whatever the null handling.

The program can be build as follows
