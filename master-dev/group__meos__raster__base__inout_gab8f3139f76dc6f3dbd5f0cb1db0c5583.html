BandStats * bandstats_in ( const char *  str)

Return raster band statistics from the text of their summarystats record.

The text is read as PostgreSQL reads the summarystats record of PostGIS: its six columns count, sum, mean, stddev, min and max are read by the rule of the PostgreSQL function record_in, the count by #int64_in and the others by #float8_in, and a NULL column, or every column but the count where it counts no pixel, reads 0, as MobilityDB reads the record of raster_summary_stats. As every input of MEOS, a NaN or an infinity is refused, and so is a count outside the 32 bits of the statistics

Parameters
[in]strString, as bandstats_out writes it
Returns
On error return NULL
