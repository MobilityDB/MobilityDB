Detailed Description

State of the aggregate uniting rasters.

The shape of PostGIS's state of ST_Union: per band of the union, the raster the pixel operation has built so far, and a second one where the operation is MEAN, kept as a count and a sum, or RANGE, kept as a minimum and a maximum
