Detailed Description

A program that tests the coordinate reference system the GeoJSON and MF-JSON representations name for the SRID of a value.

Where the caller names no system, geo_as_geojson names the one its options ask for as PostGIS function ST_AsGeoJSON does, and temporal_as_mfjson names the one of a spatial value of known SRID as the PostgreSQL function asMFJSON does, the long name where its option asks for it alone and the short one otherwise, writing the bounding box where it asks for it, both reading the name from spatial_ref_sys.csv. An SRID absent from the file is an error, reached under meos_initialize_noexit_error_handler, the handler every language binding installs.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o crs_name_test crs_name_test.c -L/usr/local/lib -lmeos
