LWGEOM * meos_linear_union ( const LWGEOM *  geom)

Return the union of the linear and point components of a geometry.

The components are read as the point set they cover: a component another one covers is left out, and what remains is the union. The rule is the one meos_areal_union() applies to surfaces – a pair sharing more than a finite set of points becomes one, a pair meeting at points only stays apart – so a circular arc is kept on its own circle where a linearization would replace it by the chain of segments approximating it

Parameters
[in]geomGeometry
Returns
The union, or NULL where the geometry carries a component that is not linear or a point, and where a coincident pair draws a fork rather than a single curve, which leaves the caller to answer it another way
