Detailed Description

A program that tests that the comparison of temporal and spatiotemporal boxes is a total order.

The B-tree index, the sorting and the sort key of a binding over the temporal and spatiotemporal boxes rely on tbox_cmp and stbox_cmp being a total order consistent with tbox_eq and stbox_eq. The program compares every pair of a set of boxes of different dimensions, value types, SRIDs and geodetic flags, and verifies that the comparison is antisymmetric and transitive, and that it answers 0 exactly when the equality answers true.

The program can be build as follows

gcc -Wall -g -I/usr/local/include -o box_order_test box_order_test.c -L/usr/local/lib -lmeos
