◆ trgeometry_motion_free()

static Temporal * trgeometry_motion_free ( const Temporal *  temp,
Pose *  frame 
)
static

Return a temporal rigid geometry moved by the rigid motion a pose states, which the function frees.

The value is split into its pose and its reference geometry and rebuilt from them, as temporal_strip_geom splits it and temporal_attach_geom rebuilds it. The motion moves the pose as tpose_motion moves a temporal pose, and a pose it takes out of the plane takes the reference geometry with it, read in the plane z = 0, since a rigid geometry states its geometry and its pose in one dimension

Parameters
[in]tempTemporal rigid geometry
[in]framePose stating the motion
