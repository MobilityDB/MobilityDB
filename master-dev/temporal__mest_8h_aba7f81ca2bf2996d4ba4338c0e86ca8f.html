Datum * mest_keys_whole ( const Temporal *  temp,
void *  boxes,
size_t  size,
int32 *  count 
)

Return the keys of a multi-entry index over the boxes of the pieces of a temporal value followed by the box of the whole value.

The box of the whole value carries the flag MEOS_FLAG_WHOLE, a structure of its own (bbox_same_structure), so that an index keeps it apart from the boxes of the pieces: a box operator reads the keys of the whole values and a value predicate those of the pieces

Parameters
[in]tempTemporal value, whose box is a tbox or an stbox
[in]boxesBoxes of the pieces, allocated with palloc
[in]sizeSize of a box
[in,out]countNumber of boxes of the pieces, then of keys
