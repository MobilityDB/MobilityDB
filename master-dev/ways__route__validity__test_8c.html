Detailed Description

Test that the MEOS build refuses a route of the ways CSV file that is not a planar line in the spatial reference system of the network.

A program that writes two network files in the current directory and removes them at the end, as ways_index_test.c writes its files. The first holds a planar line of length 5 in SRID 5676, then a line with a Z dimension, a line with an M dimension, a multiline, a line in SRID 4326 and a point; the second holds the planar line alone.

The program verifies that route_exists and route_length answer the planar line, that route_exists refuses each other route with MEOS_ERR_INVALID_ARG_VALUE, that geompoint_to_npoint refuses the first network, whose scan reaches the line with a Z dimension, and that it answers the second.

The program can be build as follows
