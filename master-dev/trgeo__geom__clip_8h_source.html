101/*****************************************************************************
102 * M2 — rotational case (2D only)
103 *
104 * Generalises the M1 API to allow non-zero rotation between pose1 and pose2.
105 * The moving body's edge endpoints in the local frame (`p_a_local`,
106 * `p_b_local`) trace circular arcs in world space under the interpolated
107 * pose. Pure-translation input (theta1 == theta2) delegates to the M1
108 * fast path internally.
109 *
110 * 3D pose input (Z-flag set) is rejected with -1; M2 is 2D only, matching
111 * the design constraint that the trgeometry / cbuffer surfaces use
112 * 2D-only kernels (PostGIS curve arithmetic and the native relationships
113 * and overlay of MEOS operate in 2D).
114 *****************************************************************************/
