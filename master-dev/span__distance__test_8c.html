Detailed Description

A program that checks the nearest approach distance of a number span to a temporal box and of a temporal number to a number span against the distance through the box of the span.

Over a grid of spans, boxes and temporal numbers on either side of each other, each answer of nad_intspan_tbox, nad_bigintspan_tbox and nad_floatspan_tbox is the distance of the box of the span to the box (nad_tboxint_tboxint, ...), and each answer of nad_tint_intspan, nad_tbigint_bigintspan and nad_tfloat_floatspan the distance of the temporal number to the box of the span (nad_tint_tbox, ...). The program can be build as follows

gcc -Wall -g -I/usr/local/include -o span_distance_test span_distance_test.c -L/usr/local/lib -lmeos
