Detailed Description

Multi-entry support of the temporal types: the keys of a value are the boxes MEOS splits it into.

The access methods of the mest extension, mgist and mspgist, index a value by several keys, which its operator classes, in the extension mobilitydb_mest, extract from the value. The keys of a temporal value are the boxes of its pieces, never the box of the whole value, so a class of these holds the predicates on the value, which a piece answers, and none of the operators answered on the bounding box of the value. The consistent functions of the GiST and SP-GiST classes serve these classes unchanged: they recheck the predicates on the value at every key. What is proper to a multi-entry class is the extraction of the keys, the parameters of the split as options of the class, and a compression that keeps a key as it is, since a key is already a box.
