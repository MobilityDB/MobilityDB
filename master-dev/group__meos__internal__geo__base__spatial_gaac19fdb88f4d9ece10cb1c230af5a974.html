GSERIALIZED * geom_shortestline ( const GSERIALIZED *  gs1,
const GSERIALIZED *  gs2 
)

Return the shortest line between two geometries.

The line is computed in 3D when the geometries have Z and in 2D otherwise, as geo_distance_fn selects the temporal distance, which refuses operands of different dimensions; this is PostGIS ST_3DShortestLine when both have Z and ST_ShortestLine otherwise

Parameters
[in]gs1,gs2Geometries
Note
PostGIS functions: LWGEOM_shortestline2d(PG_FUNCTION_ARGS), LWGEOM_shortestline3d(PG_FUNCTION_ARGS)
Operands of different dimensions read the dimensions both have
Returns
On error return NULL
