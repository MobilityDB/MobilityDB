double geom_distance2d_disc_witness ( const double *  c,
double  r,
const GSERIALIZED *  gs,
double *  seg,

Return the distance of geom_distance2d_disc, setting the segment that answers it.

The segment is the first whose distance less the radius is the least, its ends in seg as ax, ay, bx, by, a point being a segment of no length; inside is true where the answer is 0 because a polygon holds the centre, the segment then being the one found before

Parameters
[in]cCentre, two coordinates
[in]rRadius, not negative
[in]gsGeometry, not empty
[out]segEnds of the segment, or NULL
[out]insideWhether a polygon holds the centre, or NULL
