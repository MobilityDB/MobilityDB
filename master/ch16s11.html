Metrics

An area is answered in square metres by cellArea, the unit and the name every cell index shares, and in the two other units libh3 publishes by th3CellAreaKm2 and th3CellAreaRads2. A length takes a unit argument: km (default), m, or rads; passing an area unit to a length function raises an error.

  • Return the temporal area of each cell in a trajectory, in square metres, square kilometres, or square radians

    cellArea(th3index) → tfloat
th3CellAreaKm2(th3index) → tfloat
th3CellAreaRads2(th3index) → tfloat

    SELECT cellArea(th3index '871fa44a8ffffff@2001-01-01');
-- 4441914.270110932@2001-01-01
SELECT th3CellAreaKm2(th3index '871fa44a8ffffff@2001-01-01');
-- 4.441914270110932@2001-01-01
SELECT th3CellAreaRads2(th3index '871fa44a8ffffff@2001-01-01');
-- 0.000000109434431@2001-01-01

  • Return the temporal length of each directed edge in a trajectory, in kilometres, metres, or radians

    th3EdgeLengthKm(th3index) → tfloat
th3EdgeLengthM(th3index) → tfloat
th3EdgeLengthRads(th3index) → tfloat

    SELECT th3EdgeLengthKm(th3CellsToDirectedEdge(th3index '871fa44a8ffffff@2001-01-01',
    th3index '871fa44aeffffff@2001-01-01'));
-- 1.272084901305088@2001-01-01
SELECT th3EdgeLengthM(th3CellsToDirectedEdge(th3index '871fa44a8ffffff@2001-01-01',
    th3index '871fa44aeffffff@2001-01-01'));
-- 1272.0849013050881@2001-01-01
SELECT th3EdgeLengthRads(th3CellsToDirectedEdge(th3index '871fa44a8ffffff@2001-01-01',
    th3index '871fa44aeffffff@2001-01-01'));
-- 0.000199667786455@2001-01-01

  • Return the temporal great-circle distance between two temporal geodetic points (not between cells)

    greatCircleDistance(tgeogpoint,tgeogpoint,text='km') → tfloat

    The two operands are synchronised.

    SELECT greatCircleDistance(tgeogpoint 'Point(0 0)@2001-01-01',
  tgeogpoint 'Point(1 0)@2001-01-01');
-- 111.19505197522943@2001-01-01
