Generator for Temporal JSONB Types

  • random_jsonb: Generate a random JSONB document

  • random_jsonb_array: Generate a random array of JSONB documents

  • random_jsonb_set: Generate a random set of JSONB documents

  • random_tjsonb_inst: Generate a random temporal JSONB of instant subtype

  • random_tjsonb_discseq: Generate a random temporal JSONB of sequence subtype and discrete interpolation

  • random_tjsonb_seq: Generate a random temporal JSONB of sequence subtype and step interpolation

  • random_tjsonb_seqset: Generate a random temporal JSONB of sequence set subtype

The file /datagen/json/create_test_tables_tjsonb.sql provides usage examples for the functions generating random values listed above.
