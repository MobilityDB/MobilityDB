Salida de texto

  • Devolver la representación textual de un tpcpoint, o de un arreglo de ellos, y convertir un tpcpoint a texto

    asText(tpcpoint) → text
asText(tpcpoint[]) → text[]
tpcpoint::text → text

    -- The pcpoint payload renders as hex-encoded WKB.
SELECT asText(tpcpoint(pcpoint(1, 1, 1, 1), '2001-01-01'::timestamptz));
-- 5C00000001000000640000006400000064000000000000@2001-01-01

  • Devolver la representación textual de un tpcpatch, o de un arreglo de ellos, y convertir un tpcpatch a texto

    asText(tpcpatch) → text
asText(tpcpatch[]) → text[]
tpcpatch::text → text

    -- The pcpatch payload renders as hex-encoded WKB.
SELECT left(asText(tpcpatch(pcpatch(pcpoint(1, 1, 1, 1), pcpoint(1, 2, 2, 2)),
  '2001-01-01'::timestamptz)), 24);
-- EC0100000100000000000000

A diferencia de los demás tipos temporales espaciales, aquí asText no recibe un argumento maxdecimaldigits: un pcpoint o un pcpatch se imprime como el hex-WKB de su forma serializada, que no tiene decimales que redondear. Lo mismo ocurre con th3index.

La salida de texto es el subconjunto seguro de la superficie textual: no existe tpcpointFromText / tpcpatchFromText, porque pcpoint_in / pcpatch_in de pgPointCloud solo aceptan hex-WKB y el esquema no se puede reconstruir a partir de la forma textual. Para la ida y vuelta use asBinary / asHexWKB con sus funciones de análisis correspondientes.
