Métricas

Un área se devuelve en metros cuadrados mediante cellArea, la unidad y el nombre que comparte cada índice de celdas, y en las otras dos unidades que publica libh3 mediante th3CellAreaKm2 y th3CellAreaRads2. Una longitud acepta un argumento de unidad: km (por defecto), m, o rads; pasar una unidad de área a una función de longitud provoca un error.

  • Devolver el área temporal de cada celda en una trayectoria, en metros cuadrados, kilómetros cuadrados o radianes cuadrados

    cellArea(th3index) → tfloat
th3CellAreaKm2(th3index) → tfloat
th3CellAreaRads2(th3index) → tfloat

    SELECT cellArea(th3index '871fa44a8ffffff@2001-01-01');
-- 4441914.270110932@2001-01-01
SELECT th3CellAreaKm2(th3index '871fa44a8ffffff@2001-01-01');
-- 4.441914270110932@2001-01-01
SELECT th3CellAreaRads2(th3index '871fa44a8ffffff@2001-01-01');
-- 0.000000109434431@2001-01-01

  • Devolver la longitud temporal de cada arista dirigida en una trayectoria, en kilómetros, metros o radianes

    th3EdgeLengthKm(th3index) → tfloat
th3EdgeLengthM(th3index) → tfloat
th3EdgeLengthRads(th3index) → tfloat

    SELECT th3EdgeLengthKm(th3CellsToDirectedEdge(th3index '871fa44a8ffffff@2001-01-01',
    th3index '871fa44aeffffff@2001-01-01'));
-- 1.272084901305088@2001-01-01
SELECT th3EdgeLengthM(th3CellsToDirectedEdge(th3index '871fa44a8ffffff@2001-01-01',
    th3index '871fa44aeffffff@2001-01-01'));
-- 1272.0849013050881@2001-01-01
SELECT th3EdgeLengthRads(th3CellsToDirectedEdge(th3index '871fa44a8ffffff@2001-01-01',
    th3index '871fa44aeffffff@2001-01-01'));
-- 0.000199667786455@2001-01-01

  • Devolver la distancia temporal del gran círculo entre dos puntos geodésicos temporales (no entre celdas), en kilómetros, metros o radianes

    greatCircleDistanceKm(tgeogpoint,tgeogpoint) → tfloat
greatCircleDistanceM(tgeogpoint,tgeogpoint) → tfloat
greatCircleDistanceRads(tgeogpoint,tgeogpoint) → tfloat

    Los dos operandos se sincronizan.

    SELECT greatCircleDistanceKm(tgeogpoint 'Point(0 0)@2001-01-01',
  tgeogpoint 'Point(1 0)@2001-01-01');
-- 111.19505197522943@2001-01-01
SELECT greatCircleDistanceM(tgeogpoint 'Point(0 0)@2001-01-01',
  tgeogpoint 'Point(1 0)@2001-01-01');
-- 111195.05197522943@2001-01-01
SELECT greatCircleDistanceRads(tgeogpoint 'Point(0 0)@2001-01-01',
  tgeogpoint 'Point(1 0)@2001-01-01');
-- 0.017453292519943@2001-01-01
