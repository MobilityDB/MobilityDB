Indexación

Se definen clases de operadores GiST y SP-GiST para que los operadores de cuadro delimitador de la sección anterior puedan usarse con los índices correspondientes.

Cada clase de operadores lleva el nombre del tipo temporal que indexa, de modo que tcell_rtree_ops más abajo representa a th3index_rtree_ops, tquadbin_rtree_ops y ts2cell_rtree_ops, y los otros cuatro nombres igualmente.

  • Clase de operadores GiST para celdas temporales

    CREATE INDEX ON trips USING gist(cells);       -- uses th3index_rtree_ops by default
CREATE INDEX ON trips USING gist(cells th3index_rtree_ops);

    Indexa un cuadro delimitador espaciotemporal stbox por fila, la extensión geodésica de las fronteras de las celdas junto con el período de tiempo.

  • Clases de operadores SP-GiST para celdas temporales, indexadas sobre el cuadro delimitador espaciotemporal stbox. La clase de árbol cuaternario es la predeterminada; la clase de árbol k-d usa particionamiento de árbol k-d y debe nombrarse explícitamente

    CREATE INDEX ON trips USING spgist(cells);     -- uses th3index_quadtree_ops by default
CREATE INDEX ON trips USING spgist(cells th3index_kdtree_ops);

  • Clase de operadores B-tree predeterminada para celdas temporales, que ordena por el valor temporal subyacente

    CREATE INDEX ON trips USING btree(cells);      -- uses tquadbin_btree_ops by default

  • Clase de operadores hash predeterminada para celdas temporales, usada por las reuniones hash y la agregación hash

    CREATE INDEX ON trips USING hash(cells);       -- uses tquadbin_hash_ops by default
