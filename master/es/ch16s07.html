  • Insertar una celda temporal en otra, o actualizar una con otra

    insert(tcell,tcell,connect boolean=true) → tcell
update(tcell,tcell,connect boolean=true) → tcell

    SELECT insert(th3index '[871fa4418ffffff@2001-01-01,
  871fa4418ffffff@2001-01-02]', th3index '[871fa44a8ffffff@2001-01-03,
  871fa44a8ffffff@2001-01-04]');
-- [871fa4418ffffff@2001-01-01, 871fa44a8ffffff@2001-01-03, 871fa44a8ffffff@2001-01-04]
SELECT insert(tquadbin '[48a6227affffffff@2001-01-01,
  48a6227affffffff@2001-01-02]', tquadbin '[485623ffffffffff@2001-01-03,
  485623ffffffffff@2001-01-04]');
/* [48a6227affffffff@2001-01-01, 485623ffffffffff@2001-01-03,
   485623ffffffffff@2001-01-04] */
SELECT insert(ts2cell '[47c3c@2001-01-01,
  47c3c@2001-01-02]', ts2cell '[47c4@2001-01-03,
  47c4@2001-01-04]');
-- [47c3c@2001-01-01, 47c4@2001-01-03, 47c4@2001-01-04]

  • Eliminar un valor de tiempo de una celda temporal

    deleteTime(tcell,times,connect boolean=true) → tcell

    SELECT deleteTime(th3index '[871fa4418ffffff@2001-01-01,
  871fa4418ffffff@2001-01-04]', tstzspan '[2001-01-02, 2001-01-03]');
-- [871fa4418ffffff@2001-01-01, 871fa4418ffffff@2001-01-04]
SELECT deleteTime(tquadbin '[48a6227affffffff@2001-01-01,
  48a6227affffffff@2001-01-04]', tstzspan '[2001-01-02, 2001-01-03]');
-- [48a6227affffffff@2001-01-01, 48a6227affffffff@2001-01-04]
SELECT deleteTime(ts2cell '[47c3c@2001-01-01,
  47c3c@2001-01-04]', tstzspan '[2001-01-02, 2001-01-03]');
-- [47c3c@2001-01-01, 47c3c@2001-01-04]

  • Fija los valores de un bloque de píxeles de una banda de un ráster

    setValues(rast raster,nband integer,x integer,y integer,newvalueset float[],
  noset boolean[]=NULL,keepnodata boolean=false) → raster

    El ráster que devuelve ST_SetValues de PostGIS: la banda nband toma los valores de newvalueset, un arreglo de una fila o de filas de igual longitud, sobre el bloque de píxeles cuyo píxel superior izquierdo está en la columna x y la fila y, ambas a partir de 1. Un valor NULL fija el píxel al valor nodata de la banda, o al menor valor de su tipo cuando la banda no indica ninguno. Un píxel cuya marca en noset es verdadera queda como está, leyéndose las marcas sobre el bloque que comparten con los valores, y lo mismo un píxel que contiene el valor nodata cuando keepnodata es verdadero. Los píxeles del bloque que quedan fuera del ráster se omiten, y un valor que excede el tipo de píxel se lee en él como lo lee PostGIS. Se rechazan una banda que el ráster no tiene, un píxel x, y fuera de él y un arreglo de más de dos dimensiones.

    SELECT dumpValues(setValues(addBand(makeEmptyRaster(3, 2, 0, 2, 1, -1, 0, 0,
  3857), NULL::integer, '16BSI', 0, -1), 1, 2, 1, ARRAY[[1, 2], [NULL, 4]]), 1);
-- {{0,1,2},{0,NULL,4}}
