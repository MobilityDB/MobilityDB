Temporal JSON

Operaciones sobre conjuntos JSONB

  • ->, ->>, jsonbsetObjectField, jsonbsetObjectFieldText: Extraer un campo de objeto JSON especificado por una clave

  • ->, ->>, jsonbsetExtractPath, jsonbsetExtractPathText: Extraer un campo de objeto JSON especificado por una ruta

  • jsonbsetArrayElement, jsonbsetArrayElementText: Extraer un elemento de un arreglo JSON

  • intset, floatset, textset: Extraer un valor alfanumérico de un conjunto JSONB dado por una clave

  • ||: Concatenación JSONB temporal

  • -: Eliminación JSONB temporal

  • ?: Existencia en un conjunto JSONB

  • jsonbsetSet, jsonbsetSetLax: Asignación JSONB temporal

  • jsonbsetInsert: Inserción JSONB temporal

  • jsonbsetStripNulls: Devolver un conjunto JSONB sin nulos

  • @?, jsonbsetPathExists, jsonbsetPathExistsTz: ¿Devuelve la ruta JSON algún elemento para el conjunto JSONB especificado?

  • @@, jsonbsetPathMatch, jsonbsetPathMatchTz: Devolver el resultado de una comprobación de predicado de ruta JSON para un conjunto JSONB

  • jsonbsetPathQueryArray, jsonbsetPathQueryArrayTz: Devolver todos los elementos devueltos por una ruta JSON de un conjunto JSONB, como un arreglo JSON

  • jsonbsetPathQueryFirst, jsonbsetPathQueryFirstTz: Devolver el primer elemento devuelto por una ruta JSON de un conjunto JSONB

Entrada y salida

  • asText: Devolver la representación en texto bien conocido (WKT)

  • asBinary, asHexWKB: Devolver la representación en binario bien conocido (WKB) o en binario bien conocido extendido hexadecimal (HexWKB)

  • asMFJSON: Devolver la representación JSON de objetos en movimiento (MF-JSON)

  • tjsonbFromText: Entrada a partir de la representación en texto bien conocido (WKT)

  • tjsonbFromBinary, tjsonbFromHexWKB: Entrada a partir de la representación en binario bien conocido (WKB) o en binario bien conocido hexadecimal (HexWKB)

  • tjsonbFromMFJSON: Entrada a partir de la representación JSON de objetos en movimiento (MF-JSON)

Constructores

  • tjsonb: Constructor de valores JSONB temporales que tienen un valor constante

  • tjsonbSeq: Constructor de valores JSONB temporales del subtipo secuencia

  • tjsonbSeqSet, tjsonbSeqSetGaps: Constructor de valores JSONB temporales del subtipo conjunto de secuencias

Conversiones

  • ::: Convertir un JSONB temporal a un tstzspan

  • ::: Convertir entre un JSONB temporal y un texto

  • ::: Convertir entre un JSONB temporal y un texto temporal

Accesores

  • getValues: Devolver los valores

  • valueAtTimestamp: Devolver el valor en una marca de tiempo

Transformaciones

  • tjsonbInst, tjsonbSeq, tjsonbSeqSet: Transformar un JSONB temporal a otro subtipo

  • setInterp: Transformar un valor JSONB temporal a otra interpolación

Operaciones JSON temporales

  • ->, ->>, tjsonObjectField, tjsonbObjectField, tjsonbObjectFieldText: Extraer un campo de objeto JSON temporal especificado por una clave

  • ->, ->>, tjsonExtractPath, tjsonbExtractPath, tjsonbExtractPathText: Extraer un campo de objeto JSON temporal especificado por una ruta

  • tjsonArrayElement, tjsonbArrayElement, tjsonbArrayElementText: Extraer un elemento de un arreglo JSON temporal

  • tbool, tint, tfloat, ttext: Extraer un valor alfanumérico temporal de un valor JSONB temporal dado por una clave

  • ||: Concatenación JSONB temporal

  • -: Eliminación JSONB temporal

  • ?: Existencia JSONB temporal

  • @>, <@: Contiene/contenido JSONB temporal

  • tjsonbSet, tjsonbSetLax: Asignación JSONB temporal

  • tjsonbInsert: Inserción JSONB temporal

  • tjsonStripNulls, tjsonbStripNulls: Devolver un valor JSON temporal sin nulos

  • @?, tjsonbPathExists, tjsonbPathExistsTz: ¿Devuelve la ruta JSON algún elemento para el valor JSONB temporal especificado?

  • @@, tjsonbPathMatch, tjsonbPathMatchTz: Devolver el resultado de una comprobación de predicado de ruta JSON para un valor JSONB temporal

  • tjsonbPathQueryArray, tjsonbPathQueryArrayTz: Devolver todos los elementos devueltos por una ruta JSON de un valor JSONB temporal, como un arreglo JSON

  • tjsonbPathQueryFirst, tjsonbPathQueryFirstTz: Devolver el primer elemento devuelto por una ruta JSON de un valor JSONB temporal

Restricciones

  • atValue, minusValue, atValues, minusValues: Restringir a (el complemento de) un valor o un conjunto de valores

Comparaciones

  • =, <>, <, >, <=, >=: Comparaciones tradicionales

  • ?=, %=: Comparaciones siempre y alguna vez

  • ::: Comparaciones temporales

Operaciones de caja delimitadora

  • &&, <@, @>, ~=, -|-: Operadores topológicos

  • ::: Operadores de posición

Agregaciones

  • tCount: Conteo temporal

  • wCount: Conteo en ventana
