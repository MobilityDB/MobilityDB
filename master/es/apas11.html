Temporal Circular Buffers

Búferes circulares estáticos

Entrada y salida

  • asText, asEWKT: Devuelve la representación de texto conocido (Well-Known Text o WKT) o la representación extendida de texto conocido (Extended Well-Known Text o EWKT)

  • asBinary, asEWKB, asHexWKB, asHexEWKB: Devuelve la representación binaria conocida (Well-Known Binary o WKB), la representación extendida binaria conocida (Extended Well-Known Binary o EWKB), la representación hexadecimal binaria conocida (Hexadecimal Well-Known Binary o HexWKB), o la representación hexadecimal extendida binaria conocida (Hexadecimal Extended Well-Known Binary o HexEWKB)

  • cbufferFromText, cbufferFromEWKT: Entrada desde la representación de texto conocido (Well-Known Text o WKT) o desde la representación extendida de texto conocido (Extended Well-Known Text o EWKT)

  • cbufferFromBinary, cbufferFromEWKB, cbufferFromHexEWKB: Entrada desde la representación binaria conocida (Well-Known Binary o WKB), desde la representación extendida binaria conocida (Extended Well-Known Binary o EWKB), o desde la representación hexadecimal extendida binaria conocida (Hexadecimal Extended Well-Known Binary o HexEWKB)

Constructores

  • cbuffer: Constructor para búferes circulares

Conversión de tipos

  • ::: Convertir entre un búfer circular y una geometría

  • stbox: Convertir un búfer circular y, opcionalmente, una marca de tiempo o un período, a un cuadro espaciotemporal

Accesores

  • point: Devuelve el punto

  • radius: Devuelve el radio

Transformaciones

  • round: Redondear el punto y el radio del búfer circular en el número de lugares decimales

Operaciones espaciales

  • SRID, setSRID: Devuelve o establece el identificador de referencia espacial

  • transform, transformPipeline: Transformar a una referencia espacial diferente

Comparaciones

  • =, <>, <, >, <=, >=: Comparaciones tradicionales

Entrada y salida

  • asText, asEWKT: Devuelve la representación de texto conocido (Well-Known Text o WKT) o la representación extendida de texto conocido (Extended Well-Known Text o EWKT)

  • asMFJSON: Devuelve la representación JSON de características móviles (Moving Features JSON o MF-JSON)

  • asBinary, asEWKB, asHexWKB, asHexEWKB: Devuelve la representación binaria conocida (Well-Known Binary o WKB), la representación extendida binaria conocida (Extended Well-Known Binary o EWKB), la representación hexadecimal binaria conocida (Hexadecimal Well-Known Binary o HexWKB), o la representación hexadecimal extendida binaria conocida (Hexadecimal Extended Well-Known Binary o HexEWKB)

  • tcbufferFromText, tcbufferFromEWKT: Entrar a partir de la representación de texto conocido (Well-Known Text o WKT) o de la representación extendida de texto conocido (Extended Well-Known Text o EWKT)

  • tcbufferFromMFJSON: Entrar a partir de la representación JSON de características móviles (Moving Features JSON o MF-JSON)

  • tcbufferFromBinary, tcbufferFromEWKB, tcbufferFromHexEWKB: Entrar a partir de la representación binaria conocida (WKB), de la representación extendida binaria conocida (EWKB), o de la representación hexadecimal extendida binaria conocida (HexEWKB)

Constructores

  • tcbuffer: Constructor para búferes circulares temporales con valor constante

  • tcbufferSeq: Constructor para búferes circulares temporales de subtipo secuencia

  • tcbufferSeqSet, tcbufferSeqSetGaps: Constructor para búferes circulares temporales de subtipo conjunto de secuencias

  • tcbuffer: Construir un búfer circular temporal a partir de un punto de geometría temporal y un flotante temporal

Conversión de tipos

  • ::: Convertir un búfer circular temporal a un punto de geometría temporal

  • ::: Convertir un búfer circular temporal a un flotante temporal

Accesores

  • getValues: Devuelve los valores

  • points, radius: Devuelve los puntos o los radios

  • valueAtTimestamp: Devuelve el valor en una marca de tiempo

Transformaciones

  • tcbufferInst, tcbufferSeq, tcbufferSeqSet: Transformar un búfer circular temporal en otro subtipo

  • setInterp: Transformar un búfer circular temporal en otra interpolación

  • round: Redondear los puntos y los radios del búfer circular temporal en el número de lugares decimales

Modificaciones

  • appendInstant, appendSequence: Agregar un instante temporal o una secuencia temporal

  • merge, mergeAgg: Fusionar los búferes circulares temporales

Operaciones espaciales

  • SRID, setSRID: Devuelve o establece el identificador de referencia espacial

  • transform, transformPipeline: Transformar a una referencia espacial diferente

  • traversedArea: Devuelve el área atravesada por el búfer circular temporal

  • centroid: Devuelve el punto geométrico temporal dado por los centros de un búfer circular temporal

  • convexHull: Devuelve la envolvente convexa del área atravesada por el búfer circular temporal

Operaciones de distancia

  • |=|: Devuelve la distancia más cercana

  • nearestApproachInstant: TODO Devuelve el instante del primer búfer circular temporal en el que los dos argumentos están a la distancia más cercana

  • shortestLine: TODO Devuelve la línea que conecta el punto de aproximación más cercano entre los dos argumentos

  • <->: TODO Devuelve la distancia temporal

  • minDistance: Devuelve la distancia espacial mínima, ignorando el tiempo

Restricciones

  • atValue, minusValue, atValues, minusValues: Restringir al (complemento de) un valor o un conjunto de valores

  • atGeometry, minusGeometry: TODO Restringir al (complemento de) una geometría

  • atStbox, minusStbox: Restringir un búfer circular temporal a (el complemento de) una caja espaciotemporal

Comparaciones

  • =, <>, <, >, <=, >=: Comparaciones tradicionales

  • ?=, %=: Comparaciones alguna vez y siempre

  • ::: Comparaciones temporales

Operaciones de cuadro delimitador

  • &&, <@, @>, ~=, -|-: Operadores topológicos

  • ::: Operadores de posición

Relaciones espaciales

  • eContains, aContains, eDisjoint, aDisjoint, eDwithin, aDwithin, eIntersects, aIntersects, eTouches, aTouches, eCovers, aCovers: TODO Relaciones alguna vez y siempre

  • tContains, tDisjoint, tDwithin, tIntersects, tTouches: TODO Relaciones espaciotemporales

Agregaciones

  • tCount: Conteo temporal

  • wCount: Conteo de ventana

  • tCentroid: Agregar los centros de un conjunto de búferes circulares temporales en su centroide temporal, convirtiendo a tgeompoint

Simplificación

  • minDistSimplify, minTimeDeltaSimplify: Devuelve un búfer circular temporal simplificado asegurándose de que los centros consecutivos estén al menos separados por una cierta distancia o intervalo de tiempo

  • maxDistSimplify, douglasPeuckerSimplify: Devuelve un búfer circular temporal simplificado usando el algoritmo de Douglas-Peucker
