Indexing

GiST and SP-GiST operator classes are defined so the bounding-box operators of the previous section can be used with corresponding indexes.

Each operator class carries the name of the temporal type it indexes, so tcell_rtree_ops below stands for th3index_rtree_ops, tquadbin_rtree_ops, and ts2cell_rtree_ops, and the other four names likewise.

  • GiST operator class for temporal cells

    CREATE INDEX ON trips USING gist(cells);       -- uses th3index_rtree_ops by default
CREATE INDEX ON trips USING gist(cells th3index_rtree_ops);

    Indexes an stbox spatiotemporal bounding box per row, the geodetic extent of the cell boundaries together with the time period.

  • SP-GiST operator classes for temporal cells, keyed on the stbox spatiotemporal bounding box. The quadtree class is the default; the k-d tree class uses k-d tree partitioning and must be named explicitly

    CREATE INDEX ON trips USING spgist(cells);     -- uses th3index_quadtree_ops by default
CREATE INDEX ON trips USING spgist(cells th3index_kdtree_ops);

  • Default B-tree operator class for temporal cells, ordering by the underlying temporal value

    CREATE INDEX ON trips USING btree(cells);      -- uses tquadbin_btree_ops by default

  • Default hash operator class for temporal cells, used by hash joins and hash aggregation

    CREATE INDEX ON trips USING hash(cells);       -- uses tquadbin_hash_ops by default
