Spatiotemporal Types

MobilityDB provides a set of spatiotemporal types, namely, tgeometry (temporal geometry), tgeography (temporal geography), tgeompoint (temporal geometry point), tgeogpoint (temporal geography point), tcbuffer (temporal circular buffer), tnpoint (temporal network point), tpose (temporal pose), tposechain (temporal pose chain), trgeometry (temporal rigid geometry), th3index, tquadbin, and ts2cell (the temporal DGGS cell indexes), and tpcpoint (temporal point cloud point) and tpcpatch (temporal point cloud patch). At a conceptual level, these spatiotemporal types are organized in the hierarchy depicted in Figure 7.1, “Hierarchy of spatiotemporal types in MobilityDB.”.

Figure 7.1. Hierarchy of spatiotemporal types in MobilityDB.


In this chapter and the following one we cover the type TGeo and its subtypes, that is, the spatiotemporal types derived from the PostGIS types geometry and geography. In the subsequent chapters we continue describing the remaining spatiotemporal types.

The data is obtained from the National Oceanic and Atmospherique Administration (NOAA). As illustrated in the figure, the type tgeompoint allows linear interpolation, while the type tgeometry only allows step interpolation.
