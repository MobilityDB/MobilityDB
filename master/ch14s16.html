Comparisons

  • Traditional comparisons

    trgeometry {=, <>, <, >, <=, >=} trgeometry → boolean

    SELECT trgeometry 'Polygon((0 0,1 0,1 1,0 1,0 0));
    [Pose(Point(0 0), 0.0)@2001-01-01, Pose(Point(10 0), 0.0)@2001-01-02]' = 
  trgeometry 'Polygon((0 0,1 0,1 1,0 1,0 0));
    [Pose(Point(0 0), 0.0)@2001-01-01, Pose(Point(10 0), 0.0)@2001-01-02]';
-- t
SELECT trgeometry 'Polygon((0 0,1 0,1 1,0 1,0 0));
    [Pose(Point(0 0), 0.0)@2001-01-01, Pose(Point(10 0),0.0)@2001-01-02]' <> 
  trgeometry 'Polygon((0 0,1 0,1 1,0 1,0 0));
    [Pose(Point(0 0), 0.0)@2001-01-01, Pose(Point(10 0), 0.0)@2001-01-02]';
-- f

  • Ever and always comparisons

    {geometry,trgeometry} {?=, ?<>, %=, %<>} {geometry,trgeometry} → boolean

    SELECT trgeometry 'Polygon((0 0,1 0,1 1,0 1,0 0));[Pose(Point(0 0), 0.0)@2001-01-01,
  Pose(Point(5 0), 0.0)@2001-01-02]' ?= geometry 'Polygon((5 0,6 0,6 1,5 1,5 0))';
-- t

  • Ever and always overlaps

    trgeometry {?&&, %&&} stbox → boolean
stbox {?&&, %&&} trgeometry → boolean

    Whether the value lies in a spatiotemporal box at some instant, or at every instant at which it is defined, as ??? states it for the temporal geometries; a rigid geometry lies in a box when it intersects it, as the restriction of a temporal rigid geometry to a box reads it.

    SELECT trgeometry 'Polygon((0 0,1 0,0 1,0 0));[Pose(Point(0 0), 0)@2001-01-01 00:00,
  Pose(Point(10 10), 0)@2001-01-01 10:00]' ?&&
  stbox 'STBOX XT(((8,0),(10,2)),[2001-01-01 00:00, 2001-01-01 10:00])';
-- false
SELECT trgeometry 'Polygon((0 0,1 0,0 1,0 0));[Pose(Point(0 0), 0)@2001-01-01 00:00,
  Pose(Point(10 10), 0)@2001-01-01 10:00]' &&
  stbox 'STBOX XT(((8,0),(10,2)),[2001-01-01 00:00, 2001-01-01 10:00])';
-- true
SELECT trgeometry 'Polygon((0 0,1 0,0 1,0 0));[Pose(Point(0 0), 0)@2001-01-01 00:00,
  Pose(Point(10 10), 0)@2001-01-01 10:00]' ?&&
  stbox 'STBOX XT(((4,4),(6,6)),[2001-01-01 04:00, 2001-01-01 06:00])';
-- true
SELECT trgeometry 'Polygon((0 0,1 0,0 1,0 0));[Pose(Point(0 0), 0)@2001-01-01 00:00,
  Pose(Point(10 10), 0)@2001-01-01 10:00]' %&&
  stbox 'STBOX X((0,0),(9,9))';
-- false
