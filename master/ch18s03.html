Distance Operations

tDistance returns the distance between two values at each instant, as a temporal float, and nearestApproachDistance the smallest of these distances. distance and its set, span and span set forms return the distance between two values, and th3GridDistance the grid distance between two temporal H3 cells at each instant, as a temporal big integer.

tquadbinGridDistance and ts2GridDistance return the grid distance between two temporal QUADBIN or S2 cells in the same way.
